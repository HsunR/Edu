# 智慧教育平台 - 页面功能详细说明

## 1. 整体布局

应用采用经典的**侧边栏 + 顶部导航 + 主内容区**三栏布局：

```
┌─────────────────────────────────────────────┐
│  Navbar (顶部导航栏)                          │
│  [Hamburger] [Breadcrumb] [Search] [User]   │
├──────────┬──────────────────────────────────┤
│          │                                  │
│ Sidebar  │  AppMain (主内容区)               │
│ (侧边栏)  │  <router-view />                │
│          │                                  │
│ - 课程浏览│                                  │
│ - 我学的课│                                  │
│ - 我教的课│                                  │
│ - 资源管理│                                  │
│ - 设置    │                                  │
│ - 系统管理│                                  │
│          │                                  │
├──────────┴──────────────────────────────────┤
│  Copyright (可选)                             │
└─────────────────────────────────────────────┘
```

- **侧边栏**：可折叠，支持暗色/亮色主题，显示 Logo 和菜单
- **顶部导航栏**：包含折叠按钮、面包屑、搜索、全屏、用户信息
- **响应式**：窗口宽度 < 992px 自动切换为移动端模式

## 2. 登录/注册页面

**路由**：`/login`、`/register`

### 2.1 页面布局

采用翻转卡片式设计，左侧为登录/注册表单，右侧为切换面板：

```
┌──────────────────────────────────────┐
│  ┌─────────────┐  ┌───────────────┐  │
│  │  登录表单    │  │  切换面板      │  │
│  │             │  │               │  │
│  │ [手机号登录] │  │ "注册账号"    │  │
│  │ [邮箱登录]   │  │ [点击注册]    │  │
│  │ [微信登录]   │  │               │  │
│  │ [用户名登录] │  └───────────────┘  │
│  │             │                     │
│  │ 验证码输入   │                     │
│  │ [登录按钮]   │                     │
│  └─────────────┘                     │
└──────────────────────────────────────┘
```

### 2.2 登录方式

| 方式 | 枚举值 | 必填字段 | 验证码 |
|------|--------|----------|--------|
| 用户名密码 | `Username (4)` | 用户名 + 密码 | 无 |
| 手机号 | `Mobile (1)` | 手机号 + 验证码 | 60s 倒计时 |
| 邮箱 | `Email (2)` | 邮箱 + 验证码 | 60s 倒计时 |
| 微信 | `WeChat (3)` | OpenID | 无（预留） |

### 2.3 注册方式

| 方式 | 枚举值 | 必填字段 |
|------|--------|----------|
| 手机验证码注册 | `手机验证码注册` | 姓名 + 密码 + 学号 + 手机号 + 验证码 + 专业 + 年级 + 学校 |
| 邮箱验证码注册 | `邮箱验证码注册` | 姓名 + 密码 + 学号 + 邮箱 + 验证码 + 专业 + 年级 + 学校 |
| 微信注册 | `微信OpenID注册` | 预留 |

注册默认为学生角色，需填写学号、专业、年级、学校等学生信息。

## 3. 课程浏览页面（首页）

**路由**：`/index`（默认首页）

### 3.1 页面布局

```
┌────────────┬──────────────────────────────────────┐
│  课程分类    │  [搜索框]                             │
│  (树形结构)  │                                      │
│            │  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │
│  - 计算机   │  │课程1  │ │课程2  │ │课程3  │ │课程4  │ │
│    - 前端   │  │封面图  │ │封面图  │ │封面图  │ │封面图  │ │
│    - 后端   │  │名称   │ │名称   │ │名称   │ │名称   │ │
│  - 数学     │  │教师   │ │教师   │ │教师   │ │教师   │ │
│  - 英语     │  └──────┘ └──────┘ └──────┘ └──────┘ │
│            │                                      │
│  [清除筛选]  │  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │
│            │  │课程5  │ │课程6  │ │课程7  │ │课程8  │ │
│            │  └──────┘ └──────┘ └──────┘ └──────┘ │
│            │                                      │
│            │  [分页: 共 X 条  8/12/16/24 每页]      │
└────────────┴──────────────────────────────────────┘
```

### 3.2 功能说明

- **左侧分类树**：加载课程分类树形结构，点击分类筛选课程，支持清除筛选
- **搜索功能**：按课程名称搜索，回车或点击搜索按钮触发
- **课程卡片**：展示封面图、课程名称、描述、教师头像/姓名、分类标签
- **卡片交互**：悬停上浮效果，点击跳转课程详情页
- **分页**：支持 8/12/16/24 每页，显示总数、页码跳转
- **仅展示已发布课程**：查询参数 `status: CourseStatus.Published`

### 8.3 创建题目页面

**路由**：`/course/createQuestion`

支持 5 种题型：
- 单选题（`SingleChoice = 0`）
- 多选题（`MultipleChoice = 1`）
- 判断题（`TrueFalse = 2`）
- 填空题（`FillBlank = 3`）
- 简答题（`ShortAnswer = 4`）

每道题包含：题干、选项（选择题）、答案、解析、分值、难度（1-5级）

### 8.4 创建考试页面

**路由**：`/course/createExam/:id`

考试类型：
- 考试（`Exam = 0`）
- 练习（`Practice = 1`）
- 作业（`Homework = 2`）

配置项：考试名称、关联试卷、关联班级、开始/结束时间、时长、是否允许迟交

### 8.5 考试统计页面

**路由**：`/course/TeachingCourses/CourseDetails/:id/ExamStats/:examId`

展示考试统计数据：总人数、已提交、答题中、已批改、最高分、最低分、平均分

### 9.2 功能说明

- **删除**：确认后删除资源

## 13. 知识图谱页面（学生视角）

**路由**：`/course/LearningCourses/CourseDetails/:id/CurriculumMapLearning`

支持三种可视化模式：

| 模式 | 组件 | 说明 |
|------|------|------|
| 思维导图 | `MindMappingMode.vue` | 树形思维导图展示知识点 |
| 大纲模式 | `OutlineMode.vue` | 列表大纲展示知识点层级 |
| 图谱模式 | `AtlasMode.vue` | 关系图谱展示知识点关联（使用 relation-graph-vue3） |
