# 04 - 路由层重构

## 一、当前问题

### 1.1 `src/router/index.js` 问题清单

| # | 问题 | 严重程度 |
|---|------|---------|
| 1 | 使用 JS 而非 TS，无类型安全 | 🟡 |
| 2 | 所有路由定义在一个 400+ 行的文件中 | 🟡 |
| 3 | `constantRoutes` 和 `dynamicRoutes` 混在一起 | 🟢 |
| 4 | 路由 `name` 不唯一（如 `ChapterStudyLearning/:id`） | 🟡 |
| 5 | `hidden` 属性不是 Vue Router 标准属性 | 🟢 |
| 6 | 路由嵌套层级过深（3-4 层） | 🟡 |

### 1.2 `src/permission.ts` 问题

| # | 问题 | 严重程度 |
|---|------|---------|
| 1 | 混用新旧 Store（`useUserStore` from `stores` + `usePermissionStore` from `store`） | 🔴 |
| 2 | `usePermissionStore() as any` 丢失类型 | 🟡 |
| 3 | 路由守卫逻辑与路由定义分离 | 🟢 |

---

## 二、重构目标

```
src/router/
├── index.ts              # 🔄 创建路由实例 + 导入路由模块
├── routes/
│   ├── constant.ts       # 🆕 公共路由
│   ├── course.ts         # 🆕 课程相关路由
│   ├── system.ts         # 🆕 系统管理路由
│   └── dynamic.ts        # 🆕 动态路由
└── guards.ts             # 🆕 路由守卫（从 permission.ts 迁移）
```

### 3.7 `src/router/guards.ts`

```typescript
import router from './index'
import { ElMessage } from 'element-plus'
import NProgress from 'nprogress'
import 'nprogress/nprogress.css'
import { getToken } from '@/utils/auth'
import { useUserStore } from '@/stores/user'
import { usePermissionStore } from '@/stores/permission'

NProgress.configure({ showSpinner: false })

const whiteList = ['/login', '/register']

router.beforeEach(async (to, _from, next) => {
  NProgress.start()

  const token = getToken()

  if (token) {
    if (to.path === '/login') {
      next({ path: '/' })
      NProgress.done()
    } else {
      const userStore = useUserStore()
      if (userStore.userInfo) {
        next()
      } else {
        try {
          await userStore.fetchUserInfo()
          const permissionStore = usePermissionStore()
          if (!permissionStore.isRoutesGenerated) {
            permissionStore.generateRoutes()
          }
          next({ ...to, replace: true })
        } catch {
          await userStore.logout()
          ElMessage.error('获取用户信息失败，请重新登录')
          next(`/login?redirect=${to.fullPath}`)
          NProgress.done()
        }
      }
    }
  } else {
    if (whiteList.includes(to.path)) {
      next()
    } else {
      next(`/login?redirect=${to.fullPath}`)
      NProgress.done()
    }
  }
})

router.afterEach(() => {
  NProgress.done()
})
```
