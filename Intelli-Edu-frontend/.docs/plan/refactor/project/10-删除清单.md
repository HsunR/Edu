## 四、删除顺序

> ⚠️ **核心原则**：先创建新版 → 更新引用 → 验证 → 再删除旧版。绝不能先删后建！

1. **第一步**：创建新版 Store（`stores/permission.ts`、`stores/settings.ts`、`stores/tagsView.ts`），更新 `stores/index.ts` 导出，更新所有引用旧版 Store 的组件（实际有 **48 处**导入需更新，涉及 30+ 个文件），验证后删除旧版 `src/store/`
2. **第二步**：创建新版 API 文件，删除重复 API 文件（`login.ts`、`chapters.ts`），迁移 `inner.ts` 到 `course.ts`，重写 AI 模块，更新引用后删除旧文件
3. **第三步**：创建 `api/request.ts`，更新所有 API 文件的导入路径，更新 `download` 引用，验证后删除 `utils/request.ts` 和 `plugins/download.js`
4. **第四步**：创建新版工具文件（`utils/validate.ts`、`utils/index.ts`、`utils/errorCode.ts`、`utils/theme.ts`），更新引用后删除旧版 JS 文件
5. **第五步**：创建 `directives/` 目录，更新 `main.ts` 中指令注册方式，验证后删除 `directive/` 旧目录和 `plugins/` 目录
6. **第六步**：删除 `loginOld.vue`（确认 `loginNew.vue` 功能完整后）
7. **第七步**：重命名配置文件（`main.js` → `main.ts`、`settings.js` → `settings.ts`、`vite.config.js` → `vite.config.ts`）
8. **第八步**：将 Ant Design Vue 组件替换为 Element Plus（`TeachingIndex.vue`、`LearingIndex.vue`），验证后卸载 `ant-design-vue` 和 `@ant-design/icons-vue`
