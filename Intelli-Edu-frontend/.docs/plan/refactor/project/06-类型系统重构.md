# 06 - 类型系统重构

## 一、当前问题

### 1.1 魔法数字

| 位置 | 当前值 | 应改为 |
|------|--------|--------|
| `api/user/types.ts` | `loginType: '1' \| '2' \| '3' \| '4'` | `LoginType` 枚举 |
| `api/user/types.ts` | `registerType: '手机验证码注册' \| ...` | `RegisterType` 枚举 |
| `api/user/types.ts` | `sex: '未知' \| '男' \| '女'` | `Sex` 枚举 |
| `api/user/types.ts` | `status: '正常' \| '禁止'` | `UserStatus` 枚举 |
| `api/course/types.ts` | `isPublic: 0 \| 1` | `boolean` 或 `YesNo` 枚举 |
| `api/course/types.ts` | `isFree: 0 \| 1` | `boolean` 或 `YesNo` 枚举 |
| `api/course/types.ts` | `status: 0 \| 1 \| 2` | `CourseStatus` 枚举 |
| `api/exam/types.ts` | `questionType: 0 \| 1 \| 2 \| 3 \| 4` | `QuestionType` 枚举 |
| `api/exam/types.ts` | `difficulty: 1 \| 2 \| 3 \| 4 \| 5` | `Difficulty` 枚举 |
| `api/exam/types.ts` | `examType: 0 \| 1 \| 2` | `ExamType` 枚举 |
| `api/exam/types.ts` | `status: 0 \| 1 \| 2 \| 3` | `ExamStatus` / `SheetStatus` 枚举 |
| `api/exam/types.ts` | `gradingStatus: 0 \| 1 \| 2` | `GradingStatus` 枚举 |
| `api/resource/types.ts` | `resourceType: 1 \| 2 \| 3` | `ResourceType` 枚举 |
| `api/resource/types.ts` | `uploadStatus: 0 \| 1 \| 2` | `UploadStatus` 枚举 |

### 1.2 any 滥用

| 位置 | 当前 | 应改为 |
|------|------|--------|
| `api/course/types.ts` | `SectionResourceVO: { [key: string]: any }` | 定义具体字段 |
| `api/exam/types.ts` | `PaperVO.sections: any[]` | `PaperSection[]` |
| `api/exam/types.ts` | `PaperQuestionVO.questionSnapshot: any` | `QuestionSnapshot` |
| `api/exam/types.ts` | `PaperUpdateRequest.sections: any[]` | `PaperSection[]` |
| `api/system/*.ts` | 所有参数 `any` | 定义具体类型 |

### 1.3 类型不一致

| 位置 | 问题 |
|------|------|
| `api/user/types.ts` | `LoginRequest.loginType` 是字符串 `'1' \| '2' \| '3' \| '4'`，`SendLoginCodeRequest.loginType` 是 `number` |
| `api/user/types.ts` | `UserQueryRequest.sex` 是 `number`，`UserVO.sex` 是字符串 |
| `api/user/types.ts` | `UserQueryRequest.status` 是 `number`，`UserDetailVO.status` 是字符串 |
| `api/resource/types.ts` | `ResourceVO.uploadStatus` 是 `0 \| 1 \| 2`，`ResourceQueryRequest.uploadStatus` 是 `'1' \| '2' \| '3'` |

### 1.4 已有枚举未使用

`src/types/enums.ts` 已定义了 `UserType`、`Sex`、`CourseStatus` 等枚举，但 API 类型文件中没有引用。

## 三、详细重构方案

### 3.1 扩展 `src/types/enums.ts`

> ⚠️ **重要原则**：枚举值必须与后端 API 返回值保持一致！
> 后端返回中文/数字的，前端枚举值保持中文/数字，通过 label 映射提供可读性。
> 不可擅自改为英文值，否则所有枚举判断逻辑都会失效。

> **设计决策**：枚举值与后端保持一致（中文就中文，数字就数字），
> 通过 `XxxLabels` 映射提供 UI 展示用的中文标签。
> 如果后续后端改为返回英文/数字，只需修改枚举值和 Label 映射，不影响业务逻辑。
