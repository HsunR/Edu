# 路由与权限系统重构总览

## 一、重构背景

当前路由系统已完成文件拆分（从单文件拆为 `constant.ts` / `course.ts` / `system.ts` / `dynamic.ts`），但仅停留在"文件拆分"层面，核心架构问题未解决。本次重构旨在从根本上修正路由分类、权限控制和代码组织。

---

## 二、当前问题全景

### 2.1 路由分类错误（🔴 严重）

| 文件 | 当前分类 | 实际性质 | 问题 |
|------|---------|---------|------|
| `constant.ts` | 静态路由 | ✅ 正确 | 无 |
| `course.ts` | 静态路由（启动时注册） | ❌ 应为动态路由 | 204 行业务路由无需登录即可访问 |
| `system.ts` | 静态路由（启动时注册） | ❌ 应为动态路由 | 系统管理页面无需登录即可访问 |
| `dynamic.ts` | "动态路由" | ❌ 名不副实 | 仅 2 个权限分配子页面，不是真正的动态路由 |

**后果**：`router/index.ts` 中 `routes: [...constantRoutes, ...courseRoutes, ...systemRoutes]` 将所有业务路由在应用启动时全量注册，前端路由层无任何访问控制。

### 2.2 权限系统形同虚设（🔴 严重）

| 组件 | 问题 |
|------|------|
| `permissionStore.generateRoutes()` | 不做权限过滤，直接将所有 `dynamicRoutes` 添加 |
| `usePermission().hasPermission()` | 永远返回 `true`，权限检查未实现 |
| `v-hasRole` 指令 | 引用 `useUserStore().roles`，但 userStore 中不存在该属性，运行时报错 |
| `v-hasPermi` 指令 | 引用 `useUserStore().permissions`，但 userStore 中不存在该属性，运行时报错 |
| `dynamic.ts` 的 `meta.permissions` | 定义了但从未被任何代码消费 |

### 2.3 路由嵌套过深（🟡 中等）

```
/ (Layout)
└── /course/LearningCourses/CourseDetails/:id (LearingIndex.vue)
    └── AITeachingAssistantLearning (3 层嵌套)
    └── ChapterStudyLearning (3 层嵌套)
    └── ...共 8 个子路由
```

3-4 层嵌套导致：
- URL 过长且不直观
- 组件 `<router-view>` 嵌套层级深
- 路由匹配性能下降

### 2.4 路由命名与组织混乱（🟡 中等）

- `dynamic.ts` 只有 2 个路由却叫"动态路由"
- `course.ts` 和 `system.ts` 是动态路由却被当静态路由用
- `course.ts` 混入了 `/resource` 和 `/setting` 路由（不属于课程模块）
- 路由 `name` 使用 PascalCase 但与路径无对应关系

### 2.5 permissionStore 职责不清（🟡 中等）

```typescript
// 当前 permissionStore 维护了 5 个路由列表
routes           // constantRoutes + addRoutes
addRoutes        // 动态添加的路由
defaultRoutes    // constantRoutes + addRoutes（与 routes 重复）
topbarRouters    // 顶部菜单
sidebarRouters   // 侧边栏菜单
```

`routes` 和 `defaultRoutes` 内容完全相同，`topbarRouters` 和 `sidebarRouters` 也完全相同，存在大量冗余。

## 三、重构目标

### 3.1 核心原则

1. **静态路由 vs 动态路由**：只有无需登录即可访问的页面才是静态路由
2. **权限控制生效**：动态路由必须根据用户角色过滤后才注册
3. **按模块组织**：每个业务模块一个路由文件，文件名即模块名
4. **扁平化路由**：减少不必要的嵌套层级
5. **单一职责**：permissionStore 只管权限和路由生成，不存冗余数据

### 3.2 目标结构

```
src/router/
├── index.ts                    # 路由实例 + 仅注册静态路由
├── guards.ts                   # 路由守卫
├── routes/
│   ├── constant.ts             # 静态路由（无需登录）
│   └── modules/                # 动态路由模块（按业务拆分）
│       ├── index.ts            # 聚合导出所有模块
│       ├── course.ts           # 课程模块
│       ├── system.ts           # 系统管理模块
│       └── resource.ts         # 资源 + 设置模块
└── (类型定义保留在 src/types/router.ts)
```

### 3.3 目标权限模型

```
用户登录 → 获取 userInfo (含 type: Student | Teacher | Admin)
  → permissionStore.generateRoutes()
    → 根据用户类型过滤动态路由
    → 注册到 router
    → 更新侧边栏菜单
```
