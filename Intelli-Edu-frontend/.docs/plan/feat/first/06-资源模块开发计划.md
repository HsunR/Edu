## 2. API 函数

### `src/api/resource/resource.ts`

| 函数名 | 方法 | 路径 | 说明 |
|--------|------|------|------|
| `getResourceList` | GET | `/api/resource/resources` | 分页查询我的资源 |
| `getResourceDetail` | GET | `/api/resource/resources/{resourceId}` | 获取资源详情 |

| `presignVideo` | POST | `/api/resource/resources/presign/video` | 生成视频预签名URL |

## 3. 上传流程（核心）

### 3.1 文档/图片上传流程

```
1. 前端调 presignDocument / presignImage
   请求: { fileName: "example.pdf", fileSize: 102400 }
   响应: {
     resourceId: 12345,           // 预创建的资源记录ID
     uploadUrl: "https://cos.../object-key?signature=xxx",  // 预签名上传URL
     storageKey: "object-key",
     accessUrl: "https://cos.../object-key",  // 上传后的访问地址
     expiresIn: 3600              // 预签名URL过期时间（秒）
   }

2. 前端使用 PUT 方法将文件上传到 uploadUrl
   - Content-Type 设为文件对应的 MIME 类型
   - 直接上传到 COS，不经过后端

3. 上传完成后调 confirmUpload
   请求: { resourceId: 12345 }
   响应: ResourceVO（uploadStatus 变为 1=成功）
```

### 3.2 视频上传流程

```
1. 前端调 presignVideo
   请求: { fileName: "lecture.mp4", fileSize: 102400000 }
   响应: {
     resourceId: 12345,
     vodSessionKey: "abcde12345",  // 云点播上传会话Key
     mediaUploadUrls: ["https://..."],  // 视频分片上传地址列表
     coverUploadUrl: "https://...",     // 封面上传地址
     expiresIn: 3600
   }

2. 前端使用云点播 SDK 上传视频
   - 使用 vodSessionKey 和 mediaUploadUrls
   - 可选上传封面图到 coverUploadUrl

3. 上传完成后调 confirmVideoUpload
   请求: { resourceId: 12345, vodSessionKey: "abcde12345" }
   响应: ResourceDetailVO（含 videoMeta）
```

### 3.3 上传组件设计

**`src/components/ResourceUpload/index.vue`**:

```typescript
Props:
  accept: string           // 接受的文件类型
  resourceType: 1 | 2 | 3 // 资源类型
  maxFileSize: number      // 最大文件大小（字节）
  autoUpload: boolean      // 是否自动上传

Emits:
  success(resource: ResourceVO)  // 上传成功
  error(message: string)        // 上传失败

核心逻辑:
  async function handleUpload(file: File) {
    // 1. 根据资源类型获取预签名URL
    let presignResult
    if (resourceType === 1) presignResult = await presignVideo({ fileName: file.name, fileSize: file.size })
    else if (resourceType === 2) presignResult = await presignDocument({ fileName: file.name, fileSize: file.size })
    else presignResult = await presignImage({ fileName: file.name, fileSize: file.size })

    // 2. 上传文件到预签名URL
    if (resourceType === 1) {
      // 视频使用云点播SDK上传
      await uploadVideoToVod(presignResult, file)
      await confirmVideoUpload({ resourceId: presignResult.resourceId, vodSessionKey: presignResult.vodSessionKey })
    } else {
      // 文档/图片直接PUT上传
      await axios.put(presignResult.uploadUrl, file, { headers: { 'Content-Type': file.type } })
      await confirmUpload({ resourceId: presignResult.resourceId })
    }

    emit('success', result)
  }
```

## 5. 关键注意事项

1. **预签名上传**: 文件直接上传到 COS，不经过后端服务器，减轻服务器压力
2. **上传确认必须调用**: 上传文件到 COS 后，必须调 `confirmUpload` 或 `confirmVideoUpload`，否则资源状态仍为"待确认"
3. **预签名URL过期**: `expiresIn` 默认 3600 秒，前端需检查是否过期
4. **视频上传特殊**: 视频使用云点播 SDK，流程与文档/图片不同
5. **uploadStatus 枚举**: 0=待确认 1=成功 2=失败
6. **资源类型枚举**: 1=视频 2=文档 3=图片（数字，不是字符串）
7. **资源查询**: `getResourceList` 只返回当前用户上传的资源
8. **删除权限**: 只有资源所有者可以删除
9. **文件大小限制**: 前端应在选择文件时校验大小，避免无效上传
10. **视频转码**: 视频上传后可能需要转码，`transcodeStatus` 反映转码进度
11. **uploadStatus 查询参数类型不一致**: 资源自身的 `uploadStatus` 是整数（0/1/2），但查询参数 `uploadStatus` 是字符串（`"1"`/`"2"`/`"3"`），API 文档标注可用值为 `1,2,3`（字符串类型）。前端查询时需转为字符串
12. **presignDocument 示例文件名**: API 文档中 presignDocument 的示例使用了 `"example.jpg"`（图片文件名），但该接口是文档预签名。前端应确保传入正确的文件类型
