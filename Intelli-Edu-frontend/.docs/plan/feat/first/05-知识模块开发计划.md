# Phase 5 - 知识模块开发计划

## API 基础信息

- **服务地址**: `http://192.168.101.1:8895/api/knowledge`
- **接口前缀**: `/api/knowledge`

## 2. API 函数

### `src/api/knowledge/point.ts`

| 函数名 | 方法 | 路径 | 说明 |
|--------|------|------|------|
| `createPoint` | POST | `/api/knowledge/points` | 创建知识点 |
| `updatePoint` | PUT | `/api/knowledge/points/{pointId}` | 更新知识点 |
| `deletePoint` | DELETE | `/api/knowledge/points/{pointId}` | 删除知识点 |
| `getKnowledgeTree` | GET | `/api/knowledge/points/tree` | 查询知识点树（按课程） |
| `getPointQuestions` | GET | `/api/knowledge/points/{pointId}/questions` | 查看知识点关联的题目ID列表 |
| `bindQuestions` | POST | `/api/knowledge/points/{pointId}/questions` | 批量绑定题目到知识点 |
| `unbindQuestion` | DELETE | `/api/knowledge/points/{pointId}/questions/{questionId}` | 解绑题目 |
| `getPointSections` | GET | `/api/knowledge/points/{pointId}/sections` | 查看知识点关联的章节ID列表 |
| `bindSections` | POST | `/api/knowledge/points/{pointId}/sections` | 批量绑定章节到知识点 |
| `unbindSection` | DELETE | `/api/knowledge/points/{pointId}/sections/{sectionId}` | 解绑章节 |
| `getQuestionPoints` | GET | `/api/knowledge/questions/{questionId}/points` | 查看某题关联的所有知识点 |
| `getSectionPoints` | GET | `/api/knowledge/sections/{sectionId}/points` | 查看某节关联的所有知识点 |

## 3. 页面开发

### 3.1 知识点管理 `/teaching/:courseId/knowledge`

**现有文件**: `src/views/course/TeachingCourses/KnowledgePoints/`

#### 3.1.1 知识点树管理
- 调 `getKnowledgeTree(courseId)` 获取两级树形结构
- 树形组件展示（支持展开/折叠）
- 添加一级知识点：`parentId` 不传或为 null
- 添加子知识点：`parentId` 设为父知识点 ID
- 编辑知识点：名称、描述、排序
- 删除知识点
- 拖拽排序（调 `updatePoint` 修改 `orderIndex`）

#### 3.1.2 知识点关联管理
- 选中知识点后，右侧显示关联面板
- **关联题目**: 显示已关联的题目ID列表，支持添加/移除
  - 添加：弹窗选择题目（可从题库选题），调 `bindQuestions`
  - 移除：调 `unbindQuestion`
- **关联章节**: 显示已关联的章节ID列表，支持添加/移除
  - 添加：弹窗选择章节（从课程章节树选择），调 `bindSections`
  - 移除：调 `unbindSection`

### 3.2 课程地图（学生端）

**现有文件**: `src/views/course/LearningCourses/CurriculumMap/`

- 三种展示模式：
  - 思维导图模式 (`MindMappingMode.vue`)
  - 大纲模式 (`OutlineMode.vue`)
  - 图谱模式 (`AtlasMode.vue`)
- 数据源：调 `getKnowledgeTree(courseId)` 获取知识点树
- 点击知识点可查看关联的题目和章节

## 4. 关键注意事项

1. **知识点树结构**: 后端返回两级树形结构，`children` 递归嵌套
2. **知识点与课程绑定**: 每个知识点必须关联一个 `courseId`
3. **关联关系**: 知识点可关联题目和章节，是多对多关系
4. **批量绑定**: `bindQuestions` 和 `bindSections` 支持批量操作，传入 ID 数组
5. **关联查询方向**:
   - 从知识点查关联：`getPointQuestions` / `getPointSections`
   - 从题目/章节查关联：`getQuestionPoints` / `getSectionPoints`
6. **知识点树缓存**: 建议在 store 中缓存，避免频繁请求
