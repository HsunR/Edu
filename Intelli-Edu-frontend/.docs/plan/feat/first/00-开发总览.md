# Intelli-Edu 前端开发计划 - 总览

## 项目概述

Intelli-Edu（智慧教育平台）是一个面向高校的在线教学系统，支持教师授课、学生学习和AI辅助教学。项目采用微服务架构，前端为 Vue 3 + Element Plus 单页应用。

## 微服务架构

| 服务 | 端口 | API 前缀 | 说明 |
|------|------|----------|------|
| User Service | 8891 | `/api/user` | 用户鉴权与信息管理 |
| Resource Service | 8892 | `/api/resource` | 资源上传与管理 |
| Course Service | 8893 | `/api/course` | 课程、章节、班级管理 |
| Exam Service | 8894 | `/api/exam` | 题库、试卷、考试、答题 |
| Knowledge Service | 8895 | `/api/knowledge` | 知识点树与关联管理 |
| AI Service | 8896 | `/api/ai` | AI 对话与辅助教学 |

## 关键约定

### API 通用响应格式

后端返回的**分页响应**统一为 MyBatis-Plus 的 `Page<T>` 结构：

```typescript
interface PageResult<T> {
  records: T[]
  total: number
  size: number
  current: number
  pages: number
}
```

前端只需关注 `records`、`total`、`current`、`size` 四个字段，忽略 `optimizeCountSql`、`searchCount`、`orders` 等内部字段。

**非分页响应**：后端直接返回数据对象，无外层包装。API 函数的返回类型直接声明为数据类型。

### 分页请求参数

```typescript
interface PageRequest {
  current?: number
  pageSize?: number
  sortField?: string
  sortOrder?: string
}
```

### 枚举值约定

所有枚举值以 API 文档为准，不自行定义。关键枚举：

| 枚举 | 值 | 说明 |
|------|-----|------|
| UserType | Student / Teacher / Admin | 用户类型（字符串枚举） |
| Sex | 未知 / 男 / 女 | 性别（中文字符串枚举） |
| UserStatus | 正常 / 禁止 | 用户状态（中文字符串枚举） |
| RegisterType | 手机验证码注册 / 邮箱验证码注册 / 微信OpenID注册 | 注册类型（中文字符串枚举） |
| CourseStatus | 0=草稿 1=已发布 2=已归档 | 课程状态 |
| ClassStatus | 0=招生中 1=进行中 2=已结束 | 班级状态 |
| ExamType | 0=考试 1=练习 2=作业 | 考试类型 |
| ExamStatus | 0=未开始 1=进行中 2=已结束 3=已批阅完成 | 考试状态 |
| QuestionType | 0=单选 1=多选 2=判断 3=填空 4=简答 | 题目类型 |
| ResourceType | 1=视频 2=文档 3=图片 | 资源大类 |
| UploadStatus | 0=待确认 1=成功 2=失败 | 上传状态 |
| GradingStatus | 0=未批改 1=已批改 2=AI批改中 | 批改状态 |
| PaperStatus | 0=草稿 1=已发布 | 试卷状态 |
| SheetStatus | 0=未开始 1=进行中 2=已结束 3=已批阅完成 | 答卷状态 |

### ⚠️ 枚举值类型陷阱

后端枚举存在**类型不一致**问题，前端必须严格按 API 文档处理：

| 字段 | 类型 | 示例 | 说明 |
|------|------|------|------|
| `loginType` | **字符串** | `"1"`, `"2"`, `"3"`, `"4"` | 登录类型用字符串数字 |
| `registerType` | **中文字符串** | `"手机验证码注册"` | 注册类型用中文枚举 |
| `userType` | **英文字符串** | `"Student"` | 用户类型用英文枚举 |
| `sex` | **中文字符串** | `"男"` | 性别用中文枚举 |
| `status`（用户） | **中文字符串** | `"正常"` | 用户状态用中文枚举 |
| `sendLoginCode.loginType` | **整数** | `1`, `2` | 发送验证码的登录类型用整数 |
| `uploadStatus`（查询） | **字符串** | `"1"`, `"2"`, `"3"` | 资源查询的 uploadStatus 用字符串 |
| `resourceType`（节资源） | **大写字符串** | `"VIDEO"` | 节资源类型用大写英文 |
| `resourceType`（资源本身） | **整数** | `1`, `2`, `3` | 资源自身的类型用整数 |

### ⚠️ API 文档自相矛盾问题

API 文档中存在 **schema 定义与响应示例不一致** 的情况，前端需特别注意：

| 字段 | schema 定义 | 响应示例 | 处理方式 |
|------|------------|---------|---------|
| `UserVO.type` | `string`, 可用值: `Student,Teacher,Admin` | `"type": "1"` | **以 schema 为准**，使用英文枚举。示例中的 `"1"` 是后端序列化问题，实际返回应为 `"Student"` 等 |
| `UserVO.sex` | `string`, 可用值: `未知,男,女` | `"sex": "1"` | **以 schema 为准**，使用中文枚举。示例中的 `"1"` 是后端序列化问题 |
| `RegisterRequest.registerType` | `string`, 可用值: `手机验证码注册,邮箱验证码注册,微信OpenID注册` | `"registerType": "2"` | **以可用值为准**，使用中文枚举。示例中的 `"2"` 是旧版格式 |
| `ResourceQueryRequest.uploadStatus` | `string`, 可用值: `1,2,3` | — | 查询参数用字符串 `"1"/"2"/"3"`，但 VO 中是整数 `0/1/2` |

> **原则**：当 schema 定义与示例冲突时，以 schema 定义（含可用值列表）为准。若实际运行时发现后端返回值与 schema 不符，以前端实际接收到的数据为准并记录偏差。

### 文件组织约定

```
src/
  api/              # API 请求函数
    {module}/       # 按微服务模块分组
      types.ts      # 请求/响应类型
      {sub}.ts      # 子模块请求函数
      index.ts      # 统一导出
  views/            # 页面组件
    {module}/       # 按业务模块分组
  stores/           # Pinia stores（从 store/modules/ 迁移）
    {module}.ts     # 按模块拆分
  types/            # 全局共享类型
    api.ts          # 通用 API 类型
    enums.ts        # 枚举定义
  components/       # 全局组件
    ResourceUpload/ # 资源上传组件
    VideoPlayer/    # 视频播放器
    ResourceSelector/ # 资源选择器
```
