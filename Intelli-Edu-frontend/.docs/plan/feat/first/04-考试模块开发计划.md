# Phase 4 - 考试模块开发计划

## API 基础信息

- **服务地址**: `http://192.168.101.1:8894/api/exam`
- **接口前缀**: `/api/exam`

> 考试模块是业务最复杂的模块，包含 4 个子域：题库管理、题目管理、试卷管理、考试与答题。

## 3. 页面开发

### 3.1 题库管理 `/teaching/:courseId/question-bank`

**现有文件**: `src/views/course/TeachingCourses/QuestionBankManagement/`

#### 3.1.1 题库列表
- 题库卡片/表格列表（分页 + 课程过滤 + 关键词搜索）
- 创建题库弹窗：题库名称（必填）、所属课程（必填）、描述
- 编辑题库弹窗
- 删除题库（有题目时不可删，前端需提示）

#### 3.1.2 题目列表（题库内）
- 筛选条件：题型、难度、关键词
- 题目表格：题干（截断显示）、题型标签、难度星级、分值
- 创建题目弹窗/页面

**创建题目表单**（5种题型动态表单）:

| 题型 | questionType | 必填字段 | 选项 |
|------|-------------|---------|------|
| 单选题 | 0 | 题干、分值 | ≥2个选项，1个正确 |
| 多选题 | 1 | 题干、分值 | ≥2个选项，≥1个正确 |
| 判断题 | 2 | 题干、分值 | 无选项 |
| 填空题 | 3 | 题干、标准答案、分值 | 无选项 |
| 简答题 | 4 | 题干、标准答案、分值 | 无选项 |

**选项编辑器**:
- 每个选项：label（A/B/C/D）、content、isCorrect
- 单选题：isCorrect 只能选一个
- 多选题：isCorrect 可选多个
- 判断/填空/简答：无选项区域

### 3.2 试卷管理

#### 3.2.1 试卷列表
- 试卷表格（分页 + 课程过滤 + 状态过滤 + 关键词）
- 状态标签：草稿/已发布
- 操作：查看详情、编辑（仅草稿）、发布、删除（仅草稿）

#### 3.2.2 创建试卷
- 基本信息：试卷名称（必填）、所属课程（必填）
- 分节设置：`sections` 数组，每项 `{ index, title }`
  - 例：`[{ index: 1, title: "选择题" }, { index: 2, title: "简答题" }]`

#### 3.2.3 试卷详情/组卷页面
- 试卷基本信息
- 分节展示题目
- 添加题目：从题库选题弹窗（支持搜索/筛选），选择后设置分值和归属节号
- 题目排序：拖拽调整，调用 `reorderPaperQuestions`
- 移除题目
- 发布试卷：调用 `publishPaper`，冻结题目快照

**添加题目请求体**:
```json
{
  "questions": [
    { "questionId": 1, "score": 5, "sectionIndex": 1 },
    { "questionId": 2, "score": 10, "sectionIndex": 2 }
  ]
}
```

**排序请求体**:
```json
{
  "items": [
    { "id": 1, "orderIndex": 0, "sectionIndex": 1 },
    { "id": 2, "orderIndex": 1, "sectionIndex": 1 }
  ]
}
```
> 注意：排序中的 `id` 是试卷-题目关联ID（`PaperQuestionVO.id`），不是题目ID

### 3.3 考试管理

**现有文件**: `src/views/course/TeachingCourses/CourseExams/`

#### 3.3.1 考试列表
- 筛选：班级、课程、类型（考试/练习/作业）、状态
- 考试类型标签颜色区分
- 状态标签：未开始/进行中/已结束/已批阅完成

#### 3.3.2 创建考试
- 考试名称（必填）
- 选择试卷（必填，下拉选择已发布试卷）
- 选择班级（必填）
- 考试类型（必填）：考试/练习/作业
- 开放窗口：开始时间 + 结束时间（必填）
- 答题时长（分钟，可选，null=不限时）
- 是否允许迟交

#### 3.3.3 考试统计页
- 统计卡片：应考人数、已交卷、答题中、已批阅
- 分数统计：最高分、最低分、平均分
- 答卷列表：查看每个学生的答卷

#### 3.3.4 教师批阅页
- 学生答卷详情：逐题展示学生答案
- 客观题：自动判分，显示正确/错误
- 主观题：手动打分 + 评语
- 完成批阅：汇总主观题得分

### 3.4 学生答题页 `/exam/:examId/answer`

**现有文件**: `src/views/course/LearningCourses/CourseExams/`

#### 3.4.1 进入考试
- 调 `enterExam` 创建答卷，获取 `deadline`
- 倒计时显示（基于 `deadline`）
- 若已进入，调 `getMySheet` 恢复答题状态

#### 3.4.2 答题界面
- 题目导航栏（题号列表，已答/未答标记）
- 题目展示区
- 单选题：Radio 组件
- 多选题：Checkbox 组件
- 判断题：Radio（对/错）
- 填空题：Input
- 简答题：Textarea
- 每题答案实时保存：调 `saveAnswer`，写入 Redis
- 交卷按钮：调 `submitExam`

#### 3.4.3 答题结果页
- 调 `getMySheet` 查看答卷详情
- 客观题显示得分和对错
- 主观题等待批阅

## 5. 关键注意事项

1. **题目类型**: 0=单选 1=多选 2=判断 3=填空 4=简答，选项仅对单选和多选有意义
2. **难度**: 1-5 整数，前端可用星级组件展示
3. **试卷分节**: `sections` 是自定义结构 `[{ index, title }]`，用于组织试卷中的题目
4. **试卷发布**: 发布后冻结题目快照（`questionSnapshot`），不可再修改题目
5. **试卷题目排序**: `id` 是 `PaperQuestionVO.id`（关联ID），不是 `questionId`
6. **考试状态流转**: 未开始(0) → 进行中(1) → 已结束(2) → 已批阅完成(3)
7. **答卷状态**: 0=未开始 1=进行中 2=已结束 3=已批阅完成（API 文档原文："答卷状态，0=未开始 1=进行中 2=已结束 3-已批阅完成"）
8. **答题保存**: 答案写入 Redis，定时刷入 DB，前端应做自动保存（如每30秒或切题时）
9. **交卷逻辑**: 先刷 Redis → 自动判分 → 更新答卷
10. **批改状态**: 0=未批改 1=已批改 2=AI批改中
11. **客观题自动判分**: 单选、多选、判断题交卷后自动判分
12. **主观题手动批阅**: 填空、简答题需教师手动批阅
13. **完成批阅**: 教师批阅完所有主观题后调 `finishGrading`，汇总得分
14. **考试更新/删除限制**: 仅未开始的考试可修改/删除
15. **试卷更新/删除限制**: 仅草稿状态可修改/删除
16. **removePaperQuestion 路径参数**: 路径中的 `{questionId}` 实际是 `PaperQuestionVO.id`（试卷-题目关联ID），不是题目的 questionId
