## 3. 页面开发

### 3.1 登录页 `/login`

**现有文件**: `src/views/login/loginNew.vue`

**需改造内容**:
- 支持 4 种登录方式切换（用户名密码/手机号/邮箱/微信）
- 登录类型 `loginType` 映射：`'4'`=用户名密码, `'1'`=手机号, `'2'`=邮箱, `'3'`=微信
- 验证码发送按钮倒计时
- 登录成功后存储 `accessToken` + `refreshToken` + `userId` + `userType`
- 根据 `userType` 跳转：Student → 首页, Teacher → 教学课程, Admin → 管理后台

**关键逻辑**:
```
用户名密码登录: loginType='4', 必填 username + password
手机号登录: loginType='1', 必填 mobile + code (需先调 sendLoginCode)
邮箱登录: loginType='2', 必填 email + code (需先调 sendLoginCode)
微信登录: loginType='3', 必填 openId
```

### 3.2 注册页 `/register`

**需新建**: `src/views/register/index.vue`

**表单字段**:
- 注册方式切换：手机号注册(`registerType='手机验证码注册'`) / 邮箱注册(`registerType='邮箱验证码注册'`)
- 必填：姓名、密码、验证码、学号
- 选填：年级、专业、入学年份、学校
- 密码规则：必须包含字母、数字和特殊字符，6-20位

### 3.3 个人信息页 `/profile`

**现有文件**: `src/views/system/user/profile/`

**需改造内容**:
- 调用 `GET /api/user/users/me` 获取 `UserDetailVO`
- 基本信息编辑：姓名、性别、学校、个性签名
- 头像上传：先调资源预签名上传，再调 `PUT /api/user/users/me/avatar`（avatarUrl 作为 query 参数）
- 密码修改：旧密码 + 新密码
- 档案信息：根据角色显示学生档案或教师档案
- 学生：学号、年级、专业、入学年份
- 教师：工号、职称、院系、简介

### 3.4 管理员用户管理 `/admin/users`

**需改造**: `src/views/system/user/index.vue`

- 用户列表查询（分页 + 多条件过滤）
- 分配教师角色弹窗

## 5. 关键注意事项

1. **Token 存储**: `accessToken` 和 `refreshToken` 都需要持久化（localStorage，从现有 Cookie 迁移）
2. **Token 刷新**: 401 时自动调用 `/api/user/auth/refresh-token`，参数 `refreshToken` 通过 **query 参数**传递（不是请求体）
3. **注册类型枚举**: 使用中文枚举值 `'手机验证码注册'` / `'邮箱验证码注册'` / `'微信OpenID注册'`（与后端保持一致）
4. **登录类型**: 使用**字符串** `'1'`/`'2'`/`'3'`/`'4'`（不是数字！API 文档明确 loginType 为 string）
5. **发送验证码的 loginType**: 使用**整数** `1`/`2`（不是字符串！与登录请求的 loginType 类型不同，这是后端的不一致）
6. **性别枚举**: 使用中文 `'未知'`/`'男'`/`'女'`
7. **用户类型枚举**: 使用英文 `'Student'`/`'Teacher'`/`'Admin'`
8. **用户状态枚举**: 使用中文 `'正常'`/`'禁止'`
9. **头像更新**: `PUT /api/user/users/me/avatar` 的 `avatarUrl` 是 **query 参数**，不是请求体
10. **UserQueryRequest 中的 sex 和 status**: 查询参数使用**整数**（不是中文字符串），与 VO 中的字符串枚举不同
