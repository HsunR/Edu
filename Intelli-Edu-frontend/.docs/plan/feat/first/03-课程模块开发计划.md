## 3. 页面开发

### 3.1 课程浏览首页 `/`

**功能**:
- 课程分类树侧边栏（调 `getCategoryTree`，前端缓存）
- 课程卡片列表（分页 + 分类过滤 + 关键词搜索）
- 课程封面、名称、教师、简介展示

### 3.2 课程详情页 `/course/:courseId`

**功能**:
- 课程基本信息展示
- 章节目录树（折叠展开）
- 教师信息展示
- 学生：显示"加入班级"入口

### 3.3 教师教学管理 `/teaching/:courseId`

**现有文件**: `src/views/course/TeachingCourses/`

**子页面**:

#### 3.3.1 课程设置 `/teaching/:courseId/settings`
- 课程基本信息编辑
- 封面上传
- 发布/归档操作
- 课程状态：草稿→已发布→已归档

#### 3.3.2 章节管理 `/teaching/:courseId/chapters`
- 章节目录树（可拖拽排序）
- 添加/编辑/删除章
- 添加/编辑/删除节
- 节详情：资源列表管理
- 添加资源到节（选择已有资源）
- 移除节内资源
- 节内资源排序

**排序交互**: 使用拖拽组件，排序后调用 `reorderChapters` / `reorderSections`，请求体为 `OrderItem[]`：
```json
[{ "id": 1, "orderIndex": 0 }, { "id": 2, "orderIndex": 1 }]
```

#### 3.3.3 班级管理 `/teaching/:courseId/classes`
**现有文件**: `src/views/course/TeachingCourses/ClassManagement/`

- 班级列表（调 `getCourseClasses`）
- 创建班级弹窗
- 班级详情：成员列表（分页）、邀请码展示
- 移除学生
- 班级状态管理：招生中/进行中/已结束

### 3.4 学生学习页 `/learning/:courseId`

**现有文件**: `src/views/course/LearningCourses/`

**子页面**:

#### 3.4.1 课程首页
- 课程信息 + 章节目录
- 我的班级信息

#### 3.4.2 章节学习 `/learning/:courseId/section/:sectionId`
- 调 `getSectionDetail` 获取资源列表
- 视频播放器
- 文档预览
- 资源列表

#### 3.4.3 加入班级
- 输入邀请码 → 调 `joinClass`
- 我加入的班级列表 → 调 `getMyClasses`

## 5. 关键注意事项

1. **分类树缓存**: `getCategoryTree` 返回全量数据，前端应缓存到 store，不重复请求
2. **章节目录树**: `getCourseDetail` 返回的 `chapters[].sections[]` 是嵌套结构，直接渲染树形组件
3. **节详情权限**: `getSectionDetail` 需权限校验，返回含资源访问地址
4. **排序接口**: 章排序和节排序的 `OrderItem` 结构为 `{ id, orderIndex }`，`id` 是章/节的 ID
5. **资源类型枚举**: 添加资源到节时 `resourceType` 使用字符串 `'VIDEO'`/`'DOCUMENT'`/`'IMAGE'`（大写）
6. **课程删除限制**: 仅草稿状态可删除
7. **章删除级联**: 删除章会级联删除其下所有节和节-资源关联
8. **节删除级联**: 删除节会级联删除节-资源关联
9. **班级邀请码**: 创建班级后自动生成 `inviteCode`，教师可分享给学生
10. **isFree 字段**: 节的 `isFree` 为 `0`=否，`1`=是，控制是否免费预览
