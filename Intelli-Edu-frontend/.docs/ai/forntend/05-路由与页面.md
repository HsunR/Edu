# 路由与页面结构

## 路由配置位置

- **主路由文件**：`src/router/index.js`
- **权限控制**：`src/permission.js`

## 路由类型

### 1. 常量路由（constantRoutes）

所有用户都可访问的基础路由：

| 路径 | 组件 | 说明 |
|------|------|------|
| `/redirect/:path(.*)` | `views/redirect` | 重定向页面 |
| `/login` | `views/login/loginNew.vue` | 登录页 |
| `/:pathMatch(.*)*` | `views/error/404` | 404 页面 |
| `/401` | `views/error/401` | 401 页面 |
| `/index` | `views/home/index.vue` | 首页 |
| `/user/profile` | `views/system/user/profile` | 个人中心 |

### 2. 课程模块路由

课程模块是核心业务，路由结构较为复杂：

```
/course/LearningCourses              # 我学的课（列表）
/course/LearningCourses/CourseDetails/:id   # 课程详情（学生端）
  ├── AITeachingAssistantLearning   # AI助教
  ├── ChapterStudyLearning          # 章节学习
  ├── CourseWorkLearning            # 课程作业
  ├── CourseExamsLearning           # 课程考试
  ├── CourseMaterialsLearning       # 课程资料
  ├── CurriculumMapLearning         # 知识图谱
  └── ErrorSetLearning              # 错题集

/course/TeachingCourses              # 我教的课（列表）
/course/TeachingCourses/CourseDetails/:id   # 课程详情（教师端）
  ├── ClassManagementTeaching       # 课程/班级管理
  ├── ChapterStudyTeaching          # 章节学习
  ├── CourseWorkTeaching            # 课程作业
  ├── CourseExamsTeaching           # 课程考试
  ├── CourseMaterialsTeaching       # 课程资料
  ├── KnowledgePointsTeaching       # 知识点
  ├── QuestionBankManagementTeaching # 题库管理
  └── SettingManagementTeaching     # 管理设置

/course/createQuestion             # 创建题目
/course/createExam/:id             # 新建作业/考试
/course/jobLibrary                 # 作业库
/course/homeworkWorkDetail/:type/:id  # 作业/考试详情
```

### 3. 动态路由（dynamicRoutes）

基于权限动态加载的路由：

| 路径 | 权限要求 | 说明 |
|------|---------|------|
| `/system/user-auth/role/:userId` | `system:user:edit` | 分配角色 |
| `/system/role-auth/user/:roleId` | `system:role:edit` | 分配用户 |

## 路由元信息（meta）

| 属性 | 类型 | 说明 |
|------|------|------|
| `title` | string | 页面标题（侧边栏、面包屑显示） |
| `icon` | string | 图标名称（对应 `src/assets/icons/svg/`） |
| `noCache` | boolean | 是否不缓存（默认 false） |
| `breadcrumb` | boolean | 是否在面包屑显示（默认 true） |
| `activeMenu` | string | 高亮指定的侧边栏菜单 |
| `affix` | boolean | 是否固定在标签页 |

## 路由配置项说明

```javascript
{
  hidden: true,           // 不在侧边栏显示
  alwaysShow: true,       // 始终显示根路由（不管子路由数量）
  redirect: 'noRedirect', // 面包屑中不可点击
  name: 'RouterName',     // 路由名称（keep-alive 需要）
  query: '{"id": 1}',     // 默认参数
  roles: ['admin'],       // 角色权限
  permissions: ['a:a:a'], // 菜单权限
}
```

## 权限控制流程

当前项目的权限控制已简化：

1. **路由守卫**（`src/permission.js`）：
   - 不再校验登录状态（注释掉了原有逻辑）
   - 使用 `isRoutesGenerated` 判断是否已生成路由，避免重复添加
   - 直接生成所有路由并添加

```javascript
router.beforeEach(async (to, from, next) => {
  const permissionStore = usePermissionStore()
  if (!permissionStore.isRoutesGenerated) {
    const accessRoutes = await permissionStore.generateRoutes()
    accessRoutes.forEach(route => router.addRoute(route))
  }
  next()
})

router.afterEach(() => {
  NProgress.done()
})
```

## 页面布局

### 主布局（Layout）

所有业务页面都包裹在 `Layout` 组件中：

```
+------------------+
|     Navbar       |  <- 顶部导航栏（Logo、用户信息、设置）
+------------------+
| Sidebar | AppMain |  <- 侧边栏 + 主内容区（含 keep-alive）
|         |         |
|         |         |
+------------------+
```

**注意**：当前 Layout 中 TagsView（标签页导航）被注释掉了，未实际显示。

### 布局组件

| 组件 | 文件 | 说明 |
|------|------|------|
| Layout | `layout/index.vue` | 主布局容器 |
| Navbar | `layout/components/Navbar.vue` | 顶部导航栏 |
| Sidebar | `layout/components/Sidebar/` | 侧边栏菜单 |
| AppMain | `layout/components/AppMain.vue` | 主内容区（含 keep-alive） |
| TagsView | `layout/components/TagsView/` | 标签页导航 |
| Copyright | `layout/components/Copyright/` | 底部版权 |
