# 开发规范与约定

## 组件编写规范

### 单文件组件结构

项目使用 Vue 3 的 `<script setup>` 语法糖（通过 `unplugin-vue-setup-extend-plus` 支持）：

```vue
<script setup>
// 自动导入：ref, computed, onMounted, getCurrentInstance 等无需手动 import

// 组合式函数/hooks
const { proxy } = getCurrentInstance()
const route = useRoute()
const router = useRouter()

// 响应式数据
const loading = ref(false)
const list = ref([])
const queryParams = reactive({ pageNum: 1, pageSize: 10 })

// 计算属性
const computedValue = computed(() => { ... })

// 方法
function getList() { ... }

// 生命周期
onMounted(() => {
  getList()
})
</script>

<template>
  <div class="app-container">
    <!-- 页面内容 -->
  </div>
</template>

<style scoped lang="scss">
/* 样式 */
</style>
```

### 命名约定

| 类型 | 规范 | 示例 |
|------|------|------|
| 页面组件 | PascalCase，以 `Index` 结尾 | `CourseExamsIndex.vue` |
| 公共组件 | PascalCase | `Pagination.vue` |
| 组件目录 | PascalCase | `CourseExams/` |
| 路由 name | PascalCase | `CourseExamsLearning` |
| Store | camelCase，以 `use` 开头 | `useUserStore` |
| API 文件 | camelCase | `course.ts` |
| 工具函数 | camelCase | `parseTime` |

## 样式规范

### 预处理器

- 使用 **SCSS**（通过 `sass-embedded`）
- 全局样式文件位于 `src/assets/styles/`

### 全局样式文件

| 文件 | 用途 |
|------|------|
| `index.scss` | 全局样式入口 |
| `variables.module.scss` | SCSS 变量（可导出为 CSS 变量） |
| `element-ui.scss` | Element Plus 样式覆盖 |
| `sidebar.scss` | 侧边栏样式 |
| `transition.scss` | 过渡动画 |
| `mixin.scss` | SCSS Mixins |
| `ruoyi.scss` | RuoYi 框架样式 |
| `btn.scss` | 按钮样式 |
| `formBase.scss` | 表单基础样式 |

### 常用类名

- `.app-container`：页面主容器（带内边距）
- 布局类遵循 Element Plus 的命名

## 自动导入约定

由于配置了 `unplugin-auto-import`，以下 API **无需手动 import**：

### Vue API
- `ref`, `reactive`, `computed`, `watch`, `watchEffect`
- `onMounted`, `onUnmounted`, `onUpdated` 等生命周期
- `getCurrentInstance`, `nextTick`
- `defineProps`, `defineEmits`, `defineExpose`

### Vue Router API
- `useRoute`, `useRouter`
- `createRouter`, `createWebHistory`

### Pinia API
- `defineStore`, `storeToRefs`
- `acceptHMRUpdate`

### Element Plus
- 所有组件自动按需导入
- 所有图标自动导入

## API 请求规范

### 手写 API（src/api/）

```typescript
import request from '@/utils/request'

// GET 请求
export function getList(params) {
  return request({
    url: '/course/list',
    method: 'get',
    params
  })
}

// POST 请求
export function addData(data) {
  return request({
    url: '/course/add',
    method: 'post',
    data
  })
}
```

### 使用 API

```javascript
import api from '@/api/index.js'
const { CourseController } = api

// 调用
const res = await CourseController.getCourseList(params)
```

## 权限控制规范

### 指令权限

```vue
<!-- 按钮级权限 -->
<el-button v-hasPermi="['system:user:add']">新增</el-button>

<!-- 角色权限 -->
<el-button v-hasRole="['admin']">管理员操作</el-button>
```

### 路由权限

- 路由配置中通过 `permissions` 或 `roles` 控制访问
- 动态路由在 `src/router/index.js` 的 `dynamicRoutes` 中定义

## 代码生成规范

### OpenAPI 代码生成

```bash
npm run openapi
```

根据 `openapi.config.js` 配置，从后端 Swagger API 文档自动生成 TypeScript API 代码到 `src/services/` 目录。

当前配置的服务：
- user（用户服务）
- resource（资源服务）
- ai（AI 服务）

## 环境变量

| 变量 | 开发环境 | 生产环境 | 说明 |
|------|---------|---------|------|
| `VITE_APP_TITLE` | 智慧教育平台 | 智慧教育平台 | 页面标题 |
| `VITE_APP_ENV` | development | production | 环境标识 |
| `VITE_APP_BASE_API` | /api | /api | API 基础路径 |
| `VITE_BUILD_COMPRESS` | - | gzip | 构建压缩方式 |

