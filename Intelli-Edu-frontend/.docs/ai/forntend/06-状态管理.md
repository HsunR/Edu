# 状态管理（Pinia）

## Store 结构

所有 Store 位于 `src/store/modules/`，使用 Pinia 的 Options API 风格定义。

## User Store（用户状态）

**文件**：`src/store/modules/user.js`

**State**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `token` | string | JWT Token |
| `userId` | string | 用户ID |
| `username` | string | 用户名 |
| `roles` | array | 角色列表 |
| `permissions` | array | 权限列表 |
| `userInfo` | object | 用户详细信息 |
| `loginUserInfo` | object | 登录用户信息 |

**Actions**：

| 方法 | 说明 |
|------|------|
| `login(userInfo)` | 用户登录，设置 Token，自动调用 getInfo 和 getLoginUser |
| `getInfo()` | 获取用户详细信息（从 localStorage 取 userId） |
| `getLoginUser()` | 获取当前登录用户信息（调用 /user/me 接口） |
| `logOut()` | 退出登录，清除 Token 和状态 |

**注意**：当前 `roles` 和 `permissions` 字段虽然存在，但 `getLoginUser` 中相关赋值逻辑被注释掉了，实际为空数组。

**使用方式**：

```javascript
import useUserStore from '@/store/modules/user'

const userStore = useUserStore()

// 读取状态
console.log(userStore.token)
console.log(userStore.userInfo)

// 调用方法
await userStore.login({ username, password })
await userStore.logOut()
```

## Permission Store（权限路由）

**文件**：`src/store/modules/permission.js`

**State**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `routes` | array | 所有路由（常量 + 动态） |
| `addRoutes` | array | 动态添加的路由 |
| `defaultRoutes` | array | 默认路由 |
| `topbarRouters` | array | 顶部导航路由 |
| `sidebarRouters` | array | 侧边栏路由 |
| `isRoutesGenerated` | boolean | 路由是否已生成（避免重复添加） |

**Actions**：

| 方法 | 说明 |
|------|------|
| `setRoutes(routes)` | 设置路由列表 |
| `setDefaultRoutes(routes)` | 设置默认路由 |
| `setTopbarRoutes(routes)` | 设置顶部导航路由 |
| `setSidebarRouters(routes)` | 设置侧边栏路由 |
| `generateRoutes()` | 生成可访问路由，并设置 `isRoutesGenerated = true` |

**使用方式**：

```javascript
import usePermissionStore from '@/store/modules/permission'

const permissionStore = usePermissionStore()

// 获取侧边栏路由
const sidebarRoutes = permissionStore.sidebarRouters
```

## Settings Store（系统设置）

**文件**：`src/store/modules/settings.js`

**State**：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `title` | string | '' | 页面标题 |
| `theme` | string | '#409EFF' | 主题色 |
| `sideTheme` | string | `theme-dark` | 侧边栏主题 |
| `showSettings` | boolean | true | 显示设置面板 |
| `topNav` | boolean | false | 顶部导航模式 |
| `tagsView` | boolean | true | 显示标签页 |
| `tagsIcon` | boolean | false | 标签页显示图标 |
| `fixedHeader` | boolean | false | 固定头部 |
| `sidebarLogo` | boolean | true | 显示 Logo |
| `dynamicTitle` | boolean | false | 动态标题 |
| `footerVisible` | boolean | false | 显示底部版权 |
| `footerContent` | string | - | 底部版权文本 |
| `isDark` | boolean | false | 是否暗黑模式 |

**Actions**：

| 方法 | 说明 |
|------|------|
| `changeSetting({ key, value })` | 修改任意布局设置 |
| `toggleTheme()` | 切换暗黑/明亮模式 |

**使用方式**：

```javascript
import useSettingsStore from '@/store/modules/settings'

const settingsStore = useSettingsStore()

// 直接修改
settingsStore.tagsView = false

// 通过 action 修改
settingsStore.changeSetting({ key: 'tagsView', value: false })

// 切换暗黑模式
settingsStore.toggleTheme()
```

## App Store（应用状态）

**文件**：`src/store/modules/app.js`

**State**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `sidebar.opened` | boolean | 侧边栏是否展开（默认 true，持久化到 Cookie） |
| `sidebar.withoutAnimation` | boolean | 是否禁用动画 |
| `sidebar.hide` | boolean | 是否隐藏侧边栏 |
| `size` | string | 组件尺寸（large/default/small，持久化到 Cookie） |
| `device` | string | 设备类型（desktop/mobile） |

**Actions**：

| 方法 | 说明 |
|------|------|
| `toggleSideBar(withoutAnimation)` | 切换侧边栏展开/折叠 |
| `closeSideBar({ withoutAnimation })` | 关闭侧边栏 |
| `toggleSideBarHide(status)` | 切换侧边栏隐藏状态 |
| `toggleDevice(device)` | 切换设备类型 |
| `setSize(size)` | 设置组件尺寸 |

## TagsView Store（标签页）

**文件**：`src/store/modules/tagsView.js`

**State**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `visitedViews` | array | 已访问的标签页 |
| `cachedViews` | array | 缓存的视图（keep-alive） |
| `iframeViews` | array | iframe 页面视图 |

**Actions**：

| 方法 | 说明 |
|------|------|
| `addView(view)` | 添加标签页（同时添加到 visited 和 cached） |
| `addVisitedView(view)` | 添加已访问标签 |
| `addCachedView(view)` | 添加缓存视图 |
| `addIframeView(view)` | 添加 iframe 视图 |
| `delView(view)` | 删除标签页 |
| `delVisitedView(view)` | 删除已访问标签 |
| `delCachedView(view)` | 删除缓存视图 |
| `delIframeView(view)` | 删除 iframe 视图 |
| `delOthersViews(view)` | 删除其他标签页 |
| `delOthersVisitedViews(view)` | 删除其他已访问标签 |
| `delOthersCachedViews(view)` | 删除其他缓存视图 |
| `delAllViews(view)` | 删除所有标签页 |
| `delAllVisitedViews(view)` | 删除所有已访问标签（保留 affix） |
| `delAllCachedViews(view)` | 删除所有缓存视图 |
| `delRightTags(view)` | 删除右侧标签 |
| `delLeftTags(view)` | 删除左侧标签 |
| `updateVisitedView(view)` | 更新标签页信息 |

## Store 使用示例

```vue
<script setup>
// 多个 store 组合使用
import useUserStore from '@/store/modules/user'
import usePermissionStore from '@/store/modules/permission'
import useSettingsStore from '@/store/modules/settings'

const userStore = useUserStore()
const permissionStore = usePermissionStore()
const settingsStore = useSettingsStore()

// 计算属性
const isAdmin = computed(() => userStore.roles.includes('admin'))
const routes = computed(() => permissionStore.sidebarRouters)
</script>
```

## 状态持久化

- **Token**：存储在 Cookie 中（`Admin-Token`）
- **用户ID**：存储在 localStorage 中（`userId`）
- **其他状态**：Pinia 状态在内存中，刷新页面后重置
