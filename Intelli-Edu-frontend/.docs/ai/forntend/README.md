## 项目关键信息

- **框架**：Vue 3.5 + Vite 6 + Pinia 3
- **UI 库**：Element Plus + Ant Design Vue
- **语言**：JavaScript / TypeScript 混合
- **样式**：SCSS
- **构建**：Vite（端口 80）
- **基础**：基于 RuoYi-Vue 二次开发
