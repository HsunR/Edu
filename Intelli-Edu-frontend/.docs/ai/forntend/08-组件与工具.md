# 全局组件与工具库

## 全局注册组件

在 `src/main.js` 中全局注册的组件，无需 import 即可在任何页面使用：

| 组件名 | 文件 | 说明 |
|--------|------|------|
| `Pagination` | `components/Pagination` | 分页组件 |
| `RightToolbar` | `components/RightToolbar` | 表格右侧工具栏（搜索/刷新/列显隐） |
| `FileUpload` | `components/FileUpload` | 文件上传 |
| `ImageUpload` | `components/ImageUpload` | 图片上传 |
| `ImagePreview` | `components/ImagePreview` | 图片预览 |
| `Editor` | `components/Editor` | 富文本编辑器（基于 Quill） |
| `svg-icon` | `components/SvgIcon` | SVG 图标组件 |

### 使用示例

```vue
<template>
  <div>
    <!-- 分页 -->
    <Pagination
      :total="total"
      :page.sync="queryParams.pageNum"
      :limit.sync="queryParams.pageSize"
      @pagination="getList"
    />

    <!-- 富文本编辑器 -->
    <Editor v-model="form.content" />

    <!-- 文件上传 -->
    <FileUpload v-model="form.fileList" />

    <!-- SVG 图标 -->
    <svg-icon icon-class="education" />
  </div>
</template>
```

## 布局组件

### Layout（主布局）

**文件**：`src/layout/index.vue`

包含：
- 顶部导航栏（Navbar）
- 侧边栏（Sidebar）
- 标签页（TagsView）
- 主内容区（AppMain，含 keep-alive）
- 底部版权（Copyright，可选）

### Sidebar（侧边栏）

**文件**：`src/layout/components/Sidebar/index.vue`

- 基于路由配置自动生成菜单
- 支持折叠/展开
- 支持多级嵌套菜单
- 图标使用 `svg-icon` 组件

### TagsView（标签页）

**文件**：`src/layout/components/TagsView/index.vue`

- 显示已访问的页面标签
- 支持右键菜单（关闭/关闭其他/关闭全部）
- 支持缓存页面（keep-alive）

## 公共组件详情

### SvgIcon（SVG 图标）

**文件**：`src/components/SvgIcon/index.vue`

- 图标源文件位于 `src/assets/icons/svg/`
- 通过 `vite-plugin-svg-icons` 生成 SVG Sprite
- 使用方式：`<svg-icon icon-class="icon-name" />`

### Pagination（分页）

**文件**：`src/components/Pagination/index.vue`

- 基于 Element Plus 的 Pagination 封装
- 默认页码选项：`[10, 20, 30, 50]`

### Editor（富文本编辑器）

**文件**：`src/components/Editor/index.vue`

- 基于 `@vueup/vue-quill`
- 支持图片上传
- 支持 v-model 绑定

### FileUpload / ImageUpload（上传组件）

| 组件 | 说明 |
|------|------|
| FileUpload | 多文件上传，支持拖拽 |
| ImageUpload | 单图/多图上传，支持预览 |

## 自定义指令

**注册文件**：`src/directive/index.js`

### v-hasPermi（按钮权限）

**文件**：`src/directive/permission/hasPermi.js`

```vue
<el-button v-hasPermi="['system:user:add']">新增用户</el-button>
<el-button v-hasPermi="['system:user:edit']">编辑用户</el-button>
<el-button v-hasPermi="['system:user:delete']">删除用户</el-button>
```

### v-hasRole（角色权限）

**文件**：`src/directive/permission/hasRole.js`

```vue
<el-button v-hasRole="['admin']">管理员操作</el-button>
<el-button v-hasRole="['teacher']">教师操作</el-button>
```

### v-copyText（复制文本）

**文件**：`src/directive/common/copyText.js`

```vue
<el-button v-copyText="copyContent">复制</el-button>
```

## 插件

### Auth 插件（src/plugins/auth.js）

提供权限判断方法：

```javascript
import auth from '@/plugins/auth'

// 验证权限
auth.hasPermi('system:user:add')

// 验证角色
auth.hasRole('admin')
```

### Download 插件（src/plugins/download.js）

文件下载相关方法。

## 全局挂载属性

在 `src/main.js` 和 `src/plugins/index.js` 中挂载到 `app.config.globalProperties`：

| 属性 | 来源 | 说明 |
|------|------|------|
| `$download` | `utils/request` | 下载方法 |
| `$parseTime` | `utils/ruoyi` | 日期格式化 |
| `$resetForm` | `utils/ruoyi` | 表单重置 |
| `$handleTree` | `utils/ruoyi` | 树形结构处理 |
| `$addDateRange` | `utils/ruoyi` | 日期范围处理 |
| `$selectDictLabel` | `utils/ruoyi` | 字典标签 |
| `$selectDictLabels` | `utils/ruoyi` | 多选字典标签 |
| `$auth` | `plugins/auth` | 权限判断对象（hasPermi/hasRole 等） |

在组件中通过 `proxy` 访问：

```javascript
const { proxy } = getCurrentInstance()
proxy.$parseTime(new Date())
proxy.$resetForm('queryRef')
proxy.$auth.hasPermi('system:user:add')
```
