## 关键目录说明

### `src/api/` vs `src/services/`

- **`src/api/`**：手写 API 接口，当前主要使用的接口层
- **`src/services/`**：通过 `openapi.config.js` 自动生成的 API 代码目录（目前项目中不存在，尚未执行生成）

### `src/views/course/` 业务结构

课程模块是核心业务，分为两大视图：

- **LearningCourses/**：学生视角，包含学习、作业、考试、AI助教、知识图谱等
- **TeachingCourses/**：教师视角，包含课程管理、班级管理、题库管理、作业/考试发布等

两个视图有对应的详情页（`CourseDetails/:id`），通过路由参数区分课程。
