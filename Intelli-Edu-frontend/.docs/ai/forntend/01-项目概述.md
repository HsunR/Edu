# 智慧教育平台 - 项目概述

## 基本信息

| 属性 | 值 |
|------|-----|
| 项目名称 | 智慧教育平台 |
| 版本 | 3.9.0 |
| 前端框架 | Vue 3.5.16 (Composition API) |
| 构建工具 | Vite 6.3.5 |
| 状态管理 | Pinia 3.0.2 (Options API 风格) |
| 路由 | Vue Router 4.5.1 |
| UI 组件库 | Element Plus 2.9.9 + Ant Design Vue 4.2.6 |
| 语言 | JavaScript / TypeScript 混合 (API 层用 TS，组件多用 JS) |

## 项目定位

本项目是一个智慧教育平台的前端应用，基于 RuoYi-Vue 架构进行二次开发。主要功能包括：

- **课程学习**：学生端课程学习、章节学习、作业、考试、资料下载
- **教学管理**：教师端课程管理、班级管理、题库管理、作业/考试发布
- **AI 助教**：集成 AI 辅助学习功能
- **知识图谱**：课程知识结构可视化
- **系统管理**：用户、角色、菜单、部门等基础管理

## 后端服务架构

项目采用微服务架构，前端通过 `/api` 前缀代理到不同的后端服务：

| 服务 | 代理路径 | 端口 | 说明 |
|------|---------|------|------|
| AI 服务 | `/api/ai` | 8896 | AI 助教、智能相关接口 |
| 用户服务 | `/api/user/*` | 8891 | 用户认证、用户管理 |
| 资源服务 | `/api/resource/*` | 8892 | 资源管理 |
| 课程服务 | `/api/course` | 8893 | 课程核心服务 |

## 项目特点

1. **基于 RuoYi-Vue**：继承了 RuoYi 的权限管理、代码生成等能力
2. **双 UI 库**：同时使用 Element Plus 和 Ant Design Vue
3. **混合语言**：JS 和 TS 共存，API 层主要使用 TS
4. **自动代码生成**：通过 OpenAPI 规范自动生成 API 接口代码
5. **微前端代理**：开发环境通过 Vite 代理连接多个后端服务
