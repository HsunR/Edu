## 自动导入说明

项目配置了 `unplugin-auto-import` 和 `unplugin-vue-components`：

- **Element Plus 组件**：无需手动 import，自动按需导入
- **Element Plus 图标**：自动导入
- **Ant Design Vue 组件**：自动按需导入（CSS in JS 模式，`importStyle: false`）
- **Vue API**：`ref`, `reactive`, `computed`, `watch`, `getCurrentInstance` 等自动可用
- **Pinia API**：`defineStore`, `storeToRefs` 等自动可用
- **Vue Router API**：`useRoute`, `useRouter`, `createRouter`, `createWebHistory` 等自动可用

**注意**：虽然配置了自动导入，但部分组件文件仍显式 import Vue API（如 `import { ref, onMounted } from 'vue'`），这是允许的但不必要。

## 脚本命令

```bash
npm run dev           # 启动开发服务器（端口 80）
npm run build:prod    # 生产环境打包
npm run build:stage   # 预发布环境打包
npm run openapi       # 根据 OpenAPI 规范生成 API 代码
npm run preview       # 预览生产构建
```
