# 前端 AI 开发指南 - 知识模块对接

## 1. 模块概述

- **服务前缀**：`/api/knowledge`
- **端口**：8895
- **职责**：知识点的创建、管理与关联，构建课程级知识树，关联章节和题目

## 2. API 列表

### 2.1 知识点接口 (KnowledgePointController)

| 接口 | 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|------|
| 创建知识点 | POST | `/points` | 创建新知识点 | 教师 |
| 更新知识点 | PUT | `/points/{pointId}` | 更新知识点 | 教师 |
| 删除知识点 | DELETE | `/points/{pointId}` | 删除知识点 | 教师 |
| 获取知识树 | GET | `/points/tree` | 课程的两级知识树 | 任意 |
| 绑定章节 | POST | `/points/{pointId}/sections` | 批量绑定章节 | 教师 |
| 解绑章节 | DELETE | `/points/{pointId}/sections/{sectionId}` | 解绑章节 | 教师 |
| 获取关联章节 | GET | `/points/{pointId}/sections` | 查看关联章节ID | 任意 |
| 绑定题目 | POST | `/points/{pointId}/questions` | 批量绑定题目 | 教师 |
| 解绑题目 | DELETE | `/points/{pointId}/questions/{questionId}` | 解绑题目 | 教师 |
| 获取关联题目 | GET | `/points/{pointId}/questions` | 查看关联题目ID | 任意 |
| 获取节关联知识点 | GET | `/sections/{sectionId}/points` | 反向查询 | 任意 |
| 获取题关联知识点 | GET | `/questions/{questionId}/points` | 反向查询 | 任意 |

## 3. 前端页面设计

### 3.1 知识树管理 (/teacher/knowledge)

```vue
<script setup lang="ts">
import { ref, computed, onMounted } from 'vue'
import { ElMessage } from 'element-plus'
import { knowledgeApi } from '@/api/knowledge'
import type { KnowledgePointVO, KnowledgeTreeVO } from '@/types/knowledge'

const props = defineProps<{
  courseId: number
}>()

const selectedPoint = ref<KnowledgePointVO | null>(null)

const relatedQuestions = ref([])

  pointName: '',
  parentId: undefined as number | undefined,
  description: ''
})

  knowledgeTree.value.filter(p => !p.parentId)
)

const fetchTree = async () => {
  knowledgeTree.value = await knowledgeApi.getPointTree(props.courseId)
}

const handleNodeClick = async (data: KnowledgeTreeVO) => {
  selectedPoint.value = data
  // 加载关联数据
  const [sections, questions] = await Promise.all([
    knowledgeApi.getSectionIdsByPoint(data.pointId),
    knowledgeApi.getQuestionIdsByPoint(data.pointId)
  ])
  // 根据 ID 加载详情...
}

const createPoint = async () => {
  await knowledgeApi.createPoint({
    ...pointForm.value,
    courseId: props.courseId
  })
  ElMessage.success('创建成功')
  showCreatePoint.value = false
  fetchTree()
}

onMounted(fetchTree)
</script>
```

## 4. API 封装

```typescript
// api/knowledge.ts
import request from '@/utils/request'
import type {
  KnowledgePointVO, KnowledgeTreeVO,
  PointCreateRequest, PointUpdateRequest
} from '@/types/knowledge'

export const knowledgeApi = {
  createPoint: (data: PointCreateRequest) =>
    request.post<KnowledgePointVO>('/knowledge/points', data),

  updatePoint: (pointId: number, data: PointUpdateRequest) =>
    request.put<KnowledgePointVO>(`/knowledge/points/${pointId}`, data),

  deletePoint: (pointId: number) =>
    request.delete(`/knowledge/points/${pointId}`),

  getPointTree: (courseId: number) =>
    request.get<KnowledgeTreeVO[]>('/knowledge/points/tree', { params: { courseId } }),

  bindSections: (pointId: number, sectionIds: number[]) =>
    request.post(`/knowledge/points/${pointId}/sections`, { sectionIds }),

  unbindSection: (pointId: number, sectionId: number) =>
    request.delete(`/knowledge/points/${pointId}/sections/${sectionId}`),

  getSectionIdsByPoint: (pointId: number) =>
    request.get<number[]>(`/knowledge/points/${pointId}/sections`),

  bindQuestions: (pointId: number, questionIds: number[]) =>
    request.post(`/knowledge/points/${pointId}/questions`, { questionIds }),

  unbindQuestion: (pointId: number, questionId: number) =>
    request.delete(`/knowledge/points/${pointId}/questions/${questionId}`),

  getQuestionIdsByPoint: (pointId: number) =>
    request.get<number[]>(`/knowledge/points/${pointId}/questions`),

  getPointsBySection: (sectionId: number) =>
    request.get<KnowledgePointVO[]>(`/knowledge/sections/${sectionId}/points`),

  getPointsByQuestion: (questionId: number) =>
    request.get<KnowledgePointVO[]>(`/knowledge/questions/${questionId}/points`)
}
```
