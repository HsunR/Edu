# 前端 AI 开发指南 - AI 模块对接

## 1. 模块概述

- **服务前缀**：`/api/ai`
- **端口**：8081
- **职责**：AI 智能辅导、RAG 知识库问答、文档解析与向量化
- **响应方式**：SSE (Server-Sent Events) 流式响应

## 2. AI 能力介绍

| 接口 | 路径 | 说明 | 场景 |
|------|------|------|------|
| 基础流式聊天 | `/aiCourse/doChatByStream` | 仅记忆功能 | 通用对话 |
| RAG 流式聊天 | `/aiCourse/doChatWithRagByStream` | 检索增强生成 | 基于知识库问答 |
| 工具+RAG 聊天 | `/aiCourse/doChatWithToolAndRagByStream` | 多模态响应 | 复杂任务处理 |
| 文档上传聊天 | `/aiCourse/uploadChat` | 上传文档+聊天 | 文档解析问答 |

## 3. 会话管理

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 获取会话列表 | POST | `/chatList/getUserChatList` | 当前用户的所有会话 |
| 获取聊天记录 | POST | `/chatList/getChatListByConversationId` | 某会话的完整记录 |
| 创建会话 | POST | `/chatList/createChatList` | 新建聊天会话 |
| 更新会话 | POST | `/chatList/updateChatList` | 修改会话标题 |
| 删除会话 | POST | `/chatList/deleteChatList` | 删除会话 |

## 4. 流式响应处理

### 4.1 使用 Fetch + ReadableStream

由于 EventSource 不支持自定义 Header（如 Authorization），推荐使用 `fetch` + `ReadableStream`：

```typescript
// utils/sse.ts
export async function* chatStream(
  endpoint: string,
  data: { conversationId: string; userPrompt: string }
) {
  const response = await fetch(`/api/ai/aiCourse/${endpoint}`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${localStorage.getItem('accessToken')}`
    },
    body: JSON.stringify(data)
  })

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`)
  }

  const reader = response.body!.getReader()
  const decoder = new TextDecoder()
  let buffer = ''

  try {
    while (true) {
      const { done, value } = await reader.read()
      if (done) break

      buffer += decoder.decode(value, { stream: true })
      const lines = buffer.split('\n')
      buffer = lines.pop() || ''

      for (const line of lines) {
        if (line.trim()) {
          yield line
        }
      }
    }
  } finally {
    reader.releaseLock()
  }
}
```

<script setup lang="ts">
import { ref, nextTick, onMounted } from 'vue'

import type { ChatListVO, ChatMessage } from '@/types/ai'

// 状态
const chatList = ref<ChatListVO[]>([])

const messages = ref<ChatMessage[]>([])
const inputMessage = ref('')

const messagesRef = ref<HTMLElement>()
const enableUpload = ref(false)
const chatMode = ref<'chat' | 'rag' | 'tool'>('chat')

// 头像

// 创建新会话
const createNewChat = async () => {
  const res = await aiApi.createChatList({ title: '新会话' })
  currentConversationId.value = res.conversationId
  messages.value = []
  fetchChatList()
}

const switchChat = async (chat: ChatListVO) => {
  currentConversationId.value = chat.conversationId
  const res = await aiApi.getChatMessages({ conversationId: chat.conversationId })
  messages.value = res.messages || []
  scrollToBottom()
}

// 发送消息
const sendMessage = async () => {
  if (!inputMessage.value.trim() || isLoading.value) return
  if (!currentConversationId.value) {
    await createNewChat()
  }

  const userPrompt = inputMessage.value
  inputMessage.value = ''

  // 添加用户消息
  messages.value.push({
    role: 'user',
    content: userPrompt,
    time: new Date().toLocaleTimeString()
  })

  isLoading.value = true
  scrollToBottom()

  // 添加 AI 占位消息
  const aiMessageIndex = messages.value.length
  messages.value.push({
    role: 'assistant',
    content: '',
    time: new Date().toLocaleTimeString()
  })

  try {
    // 选择流式接口
    const endpointMap = {
      chat: 'doChatByStream',
      rag: 'doChatWithRagByStream',
      tool: 'doChatWithToolAndRagByStream'
    }

    const stream = chatStream(endpointMap[chatMode.value], {
      conversationId: currentConversationId.value,
      userPrompt
    })

    for await (const chunk of stream) {
      messages.value[aiMessageIndex].content += chunk
      scrollToBottom()
    }
  } catch (error) {
    ElMessage.error('聊天出错，请重试')
    messages.value[aiMessageIndex].content = '抱歉，我遇到了一些问题，请稍后重试。'
  } finally {
    isLoading.value = false
  }
}

// 文件上传

  if (!currentConversationId.value) {
    await createNewChat()
  }

  const formData = new FormData()
  formData.append('multipartFile', file)
  formData.append('conversationId', currentConversationId.value)
  formData.append('userPrompt', `请分析这个文件：${file.name}`)

  isLoading.value = true
  try {
    const stream = await aiApi.uploadChat(formData)
    // 处理流式响应...
  } finally {
    isLoading.value = false
  }
  return false  // 阻止默认上传
}

const scrollToBottom = () => {
  nextTick(() => {
    messagesRef.value!.scrollTop = messagesRef.value!.scrollHeight
  })

## 5. API 封装

```typescript
// api/ai.ts
import request from '@/utils/request'
import type {
  ChatListVO, ChatMessage, ChatRequest,
  ChatListQueryRequest, ChatListAddRequest,
  ChatListUpdateRequest, ChatListDeleteRequest
} from '@/types/ai'

export const aiApi = {
  // ===== 聊天接口（流式，需使用 fetch） =====

  /** 基础流式聊天 */
  chatStream: (data: ChatRequest) =>
    fetch('/api/ai/aiCourse/doChatByStream', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${localStorage.getItem('accessToken')}`
      },
      body: JSON.stringify(data)
    }),

  /** RAG 流式聊天 */
  chatRagStream: (data: ChatRequest) =>
    fetch('/api/ai/aiCourse/doChatWithRagByStream', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${localStorage.getItem('accessToken')}`
      },
      body: JSON.stringify(data)
    }),

  /** 工具+RAG 流式聊天 */
  chatToolStream: (data: ChatRequest) =>
    fetch('/api/ai/aiCourse/doChatWithToolAndRagByStream', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${localStorage.getItem('accessToken')}`
      },
      body: JSON.stringify(data)
    }),

  /** 上传文档+聊天 */
  uploadChat: (formData: FormData) =>
    fetch('/api/ai/aiCourse/uploadChat', {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${localStorage.getItem('accessToken')}`
      },
      body: formData
    }),

  // ===== 会话管理（走 Axios） =====

  /** 获取当前用户的会话列表 */
  getChatList: (data: ChatListQueryRequest) =>
    request.post<ChatListVO[]>('/ai/chatList/getUserChatList', data),

  /** 根据会话 ID 获取聊天记录 */
  getChatMessages: (data: ChatListQueryRequest) =>
    request.post<ChatListVO>('/ai/chatList/getChatListByConversationId', data),

  /** 创建会话 */
  createChatList: (data?: ChatListAddRequest) =>
    request.post<ChatListVO>('/ai/chatList/createChatList', data),

  /** 更新会话 */
  updateChatList: (data: ChatListUpdateRequest) =>
    request.post<ChatListVO>('/ai/chatList/updateChatList', data),

  /** 删除会话 */
  deleteChatList: (data: ChatListDeleteRequest) =>
    request.post<boolean>('/ai/chatList/deleteChatList', data)
}
```

## 6. 使用建议

### 6.1 会话管理

- 用户首次进入 AI 页面时自动创建新会话
- 会话列表存储在数据库，用户换设备可同步
- 建议限制单用户会话数量（如最多 50 个），提供批量清理功能

### 6.2 消息渲染

- AI 回复支持 Markdown 格式，使用 `marked` 或 `markdown-it` 渲染
- 代码块使用 `highlight.js` 进行语法高亮
- 数学公式可使用 `KaTeX` 渲染

### 6.3 性能优化

- 流式响应时避免频繁触发 Vue 响应式更新，可批量合并 chunk
- 长会话考虑虚拟滚动，避免 DOM 节点过多
- 图片/文件上传显示进度条

### 6.4 错误处理

- 网络中断时提示用户重试
- Token 过期时跳转登录页
- 服务繁忙时显示友好提示
