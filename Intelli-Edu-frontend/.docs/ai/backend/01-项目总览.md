# 前端 AI 开发指南 - 项目总览

## 1. 项目简介

Intelli-Edu 是一个面向教育领域的智能化微服务平台。前端需要对接的后端是基于 Spring Cloud Alibaba 构建的微服务架构，本指南专为前端开发 AI 提供完整的对接参考。

## 3. 技术栈约定

### 3.1 前端技术栈（推荐）

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 框架 | Vue 3.4+ | Composition API 为主 |
| 语言 | TypeScript 5.0+ | 严格模式 |
| 构建 | Vite 5.0+ | 快速开发构建 |
| UI 组件库 | Element Plus 2.5+ | 桌面端优先 |
| 状态管理 | Pinia 2.1+ | 替代 Vuex |
| 路由 | Vue Router 4.2+ | 支持路由守卫 |
| HTTP 客户端 | Axios 1.6+ | 统一封装拦截器 |
| 样式 | SCSS + CSS Variables | 主题定制 |
| 工具库 | VueUse + Lodash ES | 常用组合式函数 |

### 3.2 后端技术栈（了解即可）

| 层级 | 技术 |
|------|------|
| 基础框架 | Spring Boot 3.2.0, Java 21 |
| 微服务框架 | Spring Cloud 2023.0.1, Spring Cloud Alibaba 2023.0.1.0 |
| 服务注册/配置 | Nacos |
| API 网关 | Spring Cloud Gateway (端口 8890) |
| 数据库 | PostgreSQL 16+ |
| ORM | MyBatis-Plus 3.5.12 |
| 缓存 | Redis |
| 安全 | JWT (jjwt 0.12.6) |
| 文档 | Knife4j 4.4.0 (OpenAPI 3) |

## 4. 服务模块清单

| 服务名 | 职责 | 端口 | 前端请求前缀 | 主要功能 |
|--------|------|------|-------------|----------|
| Intelli-Edu-gateway | API 网关、统一认证入口 | 8890 | `http://gateway:8890` | 所有请求的统一入口 |
| Intelli-Edu-user | 用户服务 | 8891 | `/api/user` | 注册/登录/用户信息管理 |
| Intelli-Edu-resource | 资源服务 | 8892 | `/api/resource` | 文件上传/视频/图片管理 |
| Intelli-Edu-course | 课程服务 | 8893 | `/api/course` | 课程/章节/班级管理 |
| Intelli-Edu-exam | 考试服务 | 8894 | `/api/exam` | 题库/试卷/考试/答题 |
| Intelli-Edu-knowledge | 知识服务 | 8895 | `/api/knowledge` | 知识点/知识树管理 |
| Intelli-Edu-ai | AI 服务 | 8081 | `/api/ai` | AI 聊天/RAG 问答 |

## 5. 用户角色体系

| 角色值 | 角色名 | 权限说明 |
|--------|--------|----------|
| 1 | 学生 | 默认注册用户，可学习课程、参加考试、使用 AI |
| 2 | 教师 | 可创建课程、发布考试、管理班级 |
| 3 | 管理员 | 系统管理，可分配教师角色 |

**前端处理要点**：
- 登录后从 Token 解析用户角色，控制菜单和按钮显示
- 部分接口仅特定角色可调用，后端会返回 40101 无权限错误
- 教师和管理员才有内容创建权限

## 6. 开发环境配置

### 6.1 代理配置 (vite.config.ts)

```typescript
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8890',  // 网关地址
        changeOrigin: true,
        // pathRewrite 不需要，后端路由已带 /api 前缀
      }
    }
  }
})
```

### 6.2 环境变量 (.env.development)

```
VITE_API_BASE_URL=/api
VITE_GATEWAY_URL=http://localhost:8890
```
