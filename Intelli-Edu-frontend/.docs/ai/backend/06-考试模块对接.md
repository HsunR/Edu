# 前端 AI 开发指南 - 考试模块对接

## 1. 模块概述

- **服务前缀**：`/api/exam`
- **端口**：8894
- **职责**：题库管理、试卷组装、考试发布、学生答题、成绩统计与批阅

## 2. API 列表

### 2.1 题库接口 (QuestionBankController)

| 接口 | 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|------|
| 创建题库 | POST | `/question-banks` | 创建新题库 | 教师 |
| 更新题库 | PUT | `/question-banks/{bankId}` | 更新题库信息 | 教师 |
| 删除题库 | DELETE | `/question-banks/{bankId}` | 题库有题目时不可删 | 教师 |
| 查询题库 | GET | `/question-banks` | 分页查询 | 教师 |

### 2.2 题目接口 (QuestionController)

| 接口 | 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|------|
| 创建题目 | POST | `/questions/banks/{bankId}` | 在题库中创建题目 | 教师 |
| 更新题目 | PUT | `/questions/{questionId}` | 更新题目 | 教师 |
| 删除题目 | DELETE | `/questions/{questionId}` | 删除题目 | 教师 |
| 查看题目 | GET | `/questions/{questionId}` | 题目详情 | 教师 |
| 查询题目 | GET | `/questions` | 分页查询（支持过滤） | 教师 |

### 2.3 试卷接口 (PaperController)

| 接口 | 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|------|
| 创建试卷 | POST | `/papers` | 创建试卷 | 教师 |
| 更新试卷 | PUT | `/papers/{paperId}` | 仅草稿可修改 | 教师 |
| 删除试卷 | DELETE | `/papers/{paperId}` | 仅草稿可删除 | 教师 |
| 添加题目 | POST | `/papers/{paperId}/questions` | 向试卷添加题目 | 教师 |
| 移除题目 | DELETE | `/papers/{paperId}/questions/{questionId}` | 从试卷移除题目 | 教师 |
| 调整题目顺序 | PUT | `/papers/{paperId}/questions/order` | 批量排序 | 教师 |
| 发布试卷 | PUT | `/papers/{paperId}/publish` | 冻结题目快照 | 教师 |
| 查询试卷 | GET | `/papers` | 试卷列表 | 教师 |
| 试卷详情 | GET | `/papers/{paperId}` | 含完整题目列表 | 教师 |

### 2.4 考试接口 (ExamController)

| 接口 | 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|------|
| 发布考试 | POST | `/exams` | 创建考试 | 教师 |
| 更新考试 | PUT | `/exams/{examId}` | 仅未开始可修改 | 教师 |
| 删除考试 | DELETE | `/exams/{examId}` | 仅未开始可删除 | 教师 |
| 查询考试 | GET | `/exams` | 支持多条件过滤 | 任意 |
| 考试统计 | GET | `/exams/{examId}/stats` | 成绩统计 | 教师 |
| 答卷列表 | GET | `/exams/{examId}/sheets` | 查看所有答卷 | 教师 |
| 答卷详情 | GET | `/exams/sheets/{sheetId}/detail` | 批阅时查看 | 教师 |
| 批阅单题 | PUT | `/exams/records/{recordId}/grade` | 主观题打分 | 教师 |
| 完成批阅 | POST | `/exams/sheets/{sheetId}/finish-grading` | 汇总得分 | 教师 |

### 2.5 答题接口 (AnswerController)

| 接口 | 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|------|
| 进入考试 | POST | `/answers/exams/{examId}/enter` | 创建答卷 | 学生 |
| 保存答案 | PUT | `/answers/sheets/{sheetId}/questions/{questionId}` | 写入 Redis | 学生 |
| 交卷 | POST | `/answers/sheets/{sheetId}/submit` | 自动判分 | 学生 |
| 查看答卷 | GET | `/answers/exams/{examId}/my-sheet` | 含题目快照 | 学生 |

### 3.3 学生考试页面 (/exams/:id/take)

```vue
<template>
  <div class="take-exam-page">
    <!-- 考试头部信息 -->
    <el-card class="exam-header">
      <h2>{{ exam.examName }}</h2>
      <div class="exam-info">
        <span>考试时长：{{ exam.durationMinutes || '不限时' }} 分钟</span>
        <span>截止时间：{{ exam.endTime }}</span>
        <span class="countdown" v-if="remainingTime > 0">
          剩余时间：{{ formatTime(remainingTime) }}
        </span>
      </div>
    </el-card>

    <!-- 答题卡 -->
    <el-row :gutter="20">
      <el-col :span="18">
        <el-card v-for="(question, index) in questions" :key="question.questionId" class="question-card">
          <div class="question-header">
            <span class="question-number">第 {{ index + 1 }} 题</span>
            <el-tag>{{ QuestionTypeMap[question.questionType] }}</el-tag>
            <span class="question-score">{{ question.score }} 分</span>
          </div>
          <div class="question-content">{{ question.content }}</div>

          <!-- 单选题 -->
          <el-radio-group
            v-if="question.questionType === QuestionType.SINGLE_CHOICE"
            v-model="answers[question.questionId]"
            @change="saveAnswer(question.questionId)"
          >
            <el-radio
              v-for="option in question.options"
              :key="option.optionId"
              :label="option.optionLabel"
            >
              {{ option.optionLabel }}. {{ option.optionContent }}
            </el-radio>
          </el-radio-group>

          <!-- 多选题 -->
          <el-checkbox-group
            v-else-if="question.questionType === QuestionType.MULTI_CHOICE"
            v-model="answers[question.questionId]"
            @change="saveAnswer(question.questionId)"
          >
            <el-checkbox
              v-for="option in question.options"
              :key="option.optionId"
              :label="option.optionLabel"
            >
              {{ option.optionLabel }}. {{ option.optionContent }}
            </el-checkbox>
          </el-checkbox-group>

          <!-- 判断题 -->
          <el-radio-group
            v-else-if="question.questionType === QuestionType.TRUE_FALSE"
            v-model="answers[question.questionId]"
            @change="saveAnswer(question.questionId)"
          >
            <el-radio label="true">正确</el-radio>
            <el-radio label="false">错误</el-radio>
          </el-radio-group>

          <!-- 填空/简答 -->
          <el-input
            v-else
            v-model="answers[question.questionId]"
            type="textarea"
            :rows="question.questionType === QuestionType.SHORT_ANSWER ? 5 : 2"
            placeholder="请输入答案"
            @blur="saveAnswer(question.questionId)"
          />
        </el-card>

        <el-button type="primary" size="large" @click="submitExam">交卷</el-button>
      </el-col>

      <!-- 答题卡侧边栏 -->
      <el-col :span="6">
        <el-card class="answer-sheet-sidebar">
          <h3>答题卡</h3>
          <div class="answer-grid">
            <div
              v-for="(question, index) in questions"
              :key="question.questionId"
              class="answer-cell"
              :class="{ answered: answers[question.questionId] }"
              @click="scrollToQuestion(index)"
            >
              {{ index + 1 }}
            </div>
          </div>
        </el-card>
      </el-col>
    </el-row>
  </div>
</template>

<script setup lang="ts">
import { ref, onMounted, onBeforeUnmount } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { ElMessage, ElMessageBox } from 'element-plus'
import { examApi } from '@/api/exam'
import { QuestionType, QuestionTypeMap } from '@/types/enums'
import type { Exam, Question, AnswerSheetVO } from '@/types/exam'

const route = useRoute()
const router = useRouter()
const examId = Number(route.params.id)

const exam = ref<Exam>({} as Exam)
const questions = ref<Question[]>([])
const sheet = ref<AnswerSheetVO>({} as AnswerSheetVO)
const answers = ref<Record<number, any>>({})
const remainingTime = ref(0)
let timer: number

// 自动保存定时器
let autoSaveTimer: number

onMounted(async () => {
  // 进入考试，创建答卷
  const sheetRes = await examApi.enterExam(examId)
  sheet.value = sheetRes

  // 获取考试和题目信息
  const examRes = await examApi.getExamDetail(examId)
  exam.value = examRes
  questions.value = examRes.paper?.questions?.map((pq: any) => pq.question) || []

  // 计算剩余时间
  if (exam.value.durationMinutes) {
    const endTime = new Date(sheetRes.createdAt).getTime() + exam.value.durationMinutes * 60000
    remainingTime.value = Math.max(0, endTime - Date.now()) / 1000
    timer = window.setInterval(() => {
      remainingTime.value--
      if (remainingTime.value <= 0) {
        submitExam()
      }
    }, 1000)
  }

  // 自动保存（每 30 秒）
  autoSaveTimer = window.setInterval(autoSave, 30000)
})

onBeforeUnmount(() => {
  clearInterval(timer)
  clearInterval(autoSaveTimer)
})

const saveAnswer = async (questionId: number) => {
  const answerContent = Array.isArray(answers.value[questionId])
    ? answers.value[questionId].join(',')
    : String(answers.value[questionId])

  await examApi.saveAnswer(sheet.value.sheetId, questionId, { answerContent })
}

const autoSave = () => {
  // 批量保存所有已作答的题目
  Object.entries(answers.value).forEach(([questionId, _]) => {
    saveAnswer(Number(questionId))
  })
}

const submitExam = async () => {
  await ElMessageBox.confirm('确定要交卷吗？交卷后不可修改。', '确认交卷')
  await examApi.submitSheet(sheet.value.sheetId)
  ElMessage.success('交卷成功')
  router.push(`/exams/${examId}/result`)
}

const formatTime = (seconds: number) => {
  const h = Math.floor(seconds / 3600)
  const m = Math.floor((seconds % 3600) / 60)
  const s = Math.floor(seconds % 60)
  return `${h}:${m.toString().padStart(2, '0')}:${s.toString().padStart(2, '0')}`
}
</script>

  color: white;
  border-color: #67c23a;
}
</style>
```

## 4. API 封装

```typescript
// api/exam.ts
import request from '@/utils/request'
import type {
  QuestionBank, Question, QuestionCreateRequest,
  Paper, PaperVO, Exam, ExamVO, ExamStatsVO,
  AnswerSheetVO, AnswerSheetDetailVO,
  ExamCreateRequest, ExamQueryRequest, AnswerSaveRequest, GradeRequest
} from '@/types/exam'
import type { PageResult } from '@/types/common'

export const examApi = {
  // ===== 题库 =====
  createBank: (data: { bankName: string, courseId?: number }) =>
    request.post<QuestionBank>('/exam/question-banks', data),

  updateBank: (bankId: number, data: { bankName?: string }) =>
    request.put(`/exam/question-banks/${bankId}`, data),

  deleteBank: (bankId: number) =>
    request.delete(`/exam/question-banks/${bankId}`),

  listBanks: (params?: { keyword?: string }) =>
    request.get<PageResult<QuestionBank>>('/exam/question-banks', { params }),

  // ===== 题目 =====
  createQuestion: (bankId: number, data: QuestionCreateRequest) =>
    request.post<Question>(`/exam/questions/banks/${bankId}`, data),

  updateQuestion: (questionId: number, data: Partial<QuestionCreateRequest>) =>
    request.put(`/exam/questions/${questionId}`, data),

  deleteQuestion: (questionId: number) =>
    request.delete(`/exam/questions/${questionId}`),

  getQuestion: (questionId: number) =>
    request.get<Question>(`/exam/questions/${questionId}`),

  listQuestions: (params?: {
    bankId?: number, questionType?: number,
    difficulty?: number, keyword?: string
  } & PageRequest) =>
    request.get<PageResult<Question>>('/exam/questions', { params }),

  // ===== 试卷 =====
  createPaper: (data: { paperName: string, totalScore: number, durationMinutes?: number }) =>
    request.post<Paper>('/exam/papers', data),

  updatePaper: (paperId: number, data: Partial<Paper>) =>
    request.put(`/exam/papers/${paperId}`, data),

  deletePaper: (paperId: number) =>
    request.delete(`/exam/papers/${paperId}`),

  addQuestions: (paperId: number, questions: { questionId: number, score: number }[]) =>
    request.post(`/exam/papers/${paperId}/questions`, { questions }),

  removeQuestion: (paperId: number, questionId: number) =>
    request.delete(`/exam/papers/${paperId}/questions/${questionId}`),

  reorderQuestions: (paperId: number, questionIds: number[]) =>
    request.put(`/exam/papers/${paperId}/questions/order`, { questionIds }),

  publishPaper: (paperId: number) =>
    request.put(`/exam/papers/${paperId}/publish`),

  listPapers: (params?: PageRequest) =>
    request.get<PageResult<Paper>>('/exam/papers', { params }),

  getPaperDetail: (paperId: number) =>
    request.get<PaperVO>(`/exam/papers/${paperId}`),

  // ===== 考试 =====
  createExam: (data: ExamCreateRequest) =>
    request.post<ExamVO>('/exam/exams', data),

  updateExam: (examId: number, data: Partial<ExamCreateRequest>) =>
    request.put<ExamVO>(`/exam/exams/${examId}`, data),

  deleteExam: (examId: number) =>
    request.delete(`/exam/exams/${examId}`),

  listExams: (params?: ExamQueryRequest) =>
    request.get<PageResult<ExamVO>>('/exam/exams', { params }),

  getExamDetail: (examId: number) =>
    request.get<ExamVO>(`/exam/exams/${examId}`),

  getExamStats: (examId: number) =>
    request.get<ExamStatsVO>(`/exam/exams/${examId}/stats`),

  listExamSheets: (examId: number) =>
    request.get<AnswerSheetVO[]>(`/exam/exams/${examId}/sheets`),

  // ===== 批阅 =====
  getSheetDetail: (sheetId: number) =>
    request.get<AnswerSheetDetailVO>(`/exam/exams/sheets/${sheetId}/detail`),

  gradeRecord: (recordId: number, data: GradeRequest) =>
    request.put(`/exam/exams/records/${recordId}/grade`, data),

  finishGrading: (sheetId: number) =>
    request.post(`/exam/exams/sheets/${sheetId}/finish-grading`),

  // ===== 答题 =====
  enterExam: (examId: number) =>
    request.post<AnswerSheetVO>(`/exam/answers/exams/${examId}/enter`),

  saveAnswer: (sheetId: number, questionId: number, data: AnswerSaveRequest) =>
    request.put(`/exam/answers/sheets/${sheetId}/questions/${questionId}`, data),

  submitSheet: (sheetId: number) =>
    request.post(`/exam/answers/sheets/${sheetId}/submit`),

  getMySheet: (examId: number) =>
    request.get<AnswerSheetDetailVO>(`/exam/answers/exams/${examId}/my-sheet`)
}
```
