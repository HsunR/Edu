# Intelli-Edu 智慧教育平台 — 交互设计文稿

## 一、项目概述

Intelli-Edu 是一个面向高校的智慧教育平台，支持三种用户角色：**学生（Student）**、**教师（Teacher）**、**管理员（Admin）**。平台核心功能围绕课程管理、在线学习、AI助教、考试测评和系统管理展开。

### 技术栈
- **前端框架**：Vue 3 + TypeScript
- **UI 组件库**：Element Plus
- **状态管理**：Pinia
- **路由**：Vue Router 4（History 模式）
- **构建工具**：Vite

### 用户角色与权限

| 角色 | 权限范围 |
|------|---------|
| 学生 | 课程浏览、我学的课、个人中心、资源管理、设置 |
| 教师 | 课程浏览、我学的课、我教的课、个人中心、资源管理、设置 |
| 管理员 | 全部功能，含系统管理模块 |

## 三、登录/注册模块

### 3.1 登录页 `/login`

**页面描述**：双面板切换式登录/注册页面，左侧为操作区，右侧为切换引导区。

**交互流程**：

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   ┌──────────────────────┐    ┌──────────────────────┐      │
│   │                      │    │                      │      │
│   │     登录表单          │    │   注册账号           │      │
│   │                      │    │   点击注册 ──────►   │      │
│   │  登录方式：           │    │                      │      │
│   │  📱 手机  📧 邮箱    │    │   或                 │      │
│   │  💬 微信  👤 用户名   │    │                      │      │
│   │                      │    │   已有账号           │      │
│   │  [输入框]            │    │   点击登录 ◄──────   │      │
│   │  [验证码/密码]        │    │                      │      │
│   │                      │    │                      │      │
│   │  忘记密码？           │    │                      │      │
│   │                      │    │                      │      │
│   │  选择登录方式         │    │                      │      │
│   │  📱 📧 💬 👤         │    │                      │      │
│   │                      │    │                      │      │
│   │  [ 登 录 ]           │    │                      │      │
│   │                      │    │                      │      │
│   └──────────────────────┘    └──────────────────────┘      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**登录方式**：

| 方式 | 输入字段 | 验证方式 |
|------|---------|---------|
| 用户名登录 | 用户名 + 密码 | 密码校验 |
| 手机号登录 | 手机号 + 验证码 | 短信验证码 |
| 邮箱登录 | 邮箱 + 验证码 | 邮箱验证码 |
| 微信登录 | OpenID | 微信授权（未开发） |

**注册方式**：

| 方式 | 必填字段 |
|------|---------|
| 手机号注册 | 姓名、密码、学号、手机号、验证码、专业、年级、学校 |
| 邮箱注册 | 姓名、密码、学号、邮箱、验证码、专业、年级、学校 |
| 微信注册 | （未开发） |

**交互细节**：
- 登录/注册面板通过动画切换（1.25s 过渡）
- 验证码发送后 60 秒倒计时，期间按钮禁用
- 登录成功后跳转到 redirect 参数指定页面或首页
- 注册成功后自动切换回登录面板
