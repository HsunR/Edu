# 前后端功能对照

本前端仅保留当前 Spring Cloud 后端已有 Controller 支持的功能。

## 已接入

- 用户：账号密码登录、邮箱验证码登录、邮箱学生注册、当前用户资料、密码修改、用户查询、删除、分配教师。
- 课程：公开课程分页与分类、课程详情与目录、小节资源访问、学生班级加入/退出、教师课程创建/编辑/发布/归档/删除。
- 班级：教师创建班级、复制邀请码、分页查看成员和移除成员。
- 考试：考试/练习/作业分页列表；学生进入考试、加载答卷、逐题保存和交卷。
- 资源：个人资源分页、预签名上传、上传进度、上传确认、访问与删除。
- 学情：学生掌握度、薄弱点、错题与标记解决；教师班级掌握度。

## 已从前端移除

- AI 学伴：`Intelli-Edu-Ai` 当前没有 Controller，网关也没有 `/api/ai/**` 路由。
- 角色、菜单、部门、通知管理：后端没有对应 Controller。
- 虚构的学习时长、连续学习、徽章、活跃度等统计。
- 前端身份模拟切换和所有本地演示业务数据。

接口统一通过 Vite 将 `/api` 转发至网关 `http://localhost:8890`。

## 前端可靠性处理

- Access Token 过期后使用 Refresh Token 合并刷新，刷新失败会清理会话并返回登录页。
- 19 位雪花 ID 使用无损 JSON 解析并作为字符串透传，禁止转成 JavaScript `number`。
- 对后端分页 `total=0` 但仍返回记录的情况做兼容，避免隐藏已有数据与翻页入口。
- 破坏性操作使用统一确认弹窗，成功与失败使用非阻塞提示。
